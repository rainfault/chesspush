# ChessPush — упрощение интерфейса, alpha.6

18 октября 2026. Реализована новая компоновка по последнему запросу пользователя. ChessPush 0.2.0-alpha.6 установлен и запущен обычным ярлыком. Подтверждены исходный код, релизная сборка, изолированные GUI-проверки и работа установленной версии на пользовательских данных.

Каждый прикреплённый файл остаётся обычным версионируемым `KnowledgeDocument + Chapter + VariationTree`. Общий репертуар — производная проекция того же дерева, без отдельного формата или хранилища. Исходный PGN, комментарии, NAG, RAV, стрелки, ID и версии сохраняются. Отсоединение файла обратимо. Старые документы доступны в свёрнутом списке и включаются в покрытие только явным действием. Подготовленные варианты не увеличивают число сыгранных партий и их результаты.

Схема SQLite остаётся **7**, новых миграций нет. Существующие определения метрик, движковые оценки, партии, граница T0 и авторизация не заменялись. Аналитические функции, убранные с основного экрана, сохранены в backend. Архитектурные документы не переписывались под новую компоновку.

GUI-сценарии использовали собранный production frontend и настоящий Rust/SQLite backend в отдельном QA-профиле. В диалогах открытия/сохранения файлов управлялся только выбор пути. Подставных значений статистики не использовалось. Ошибок JavaScript в перечисленных сценариях нет. В PGN-сценарии хеш фактических партий, исходных payload, T0 и движковых результатов до/после одинаков: `9e47c6d0527d8ab78e784eef954b9e3c39acd8a17b3eca8354e0e4bd4fd990ed`. Это отдельная проверка тестового профиля; установленная версия дополнительно проверена на реальных пользовательских данных.

При проверке найден и исправлен переход из общего репертуара к списку при обновлении постороннего документа: теперь проекция обновляется с сохранением выбранной позиции. Повторный GUI-прогон прошёл.

Ограничения текущей реализации:

- Прикрепление сохраняет снимок PGN в базе. Изменения внешнего файла автоматически не отслеживаются.
- Общий репертуар просматривается как объединение; редактирование открывает исходный фрагмент, чтобы сохранять происхождение правок.
- PGN должен быть UTF-8, размером до 8 МБ на файл. Общая модель ограничена 50 000 узлов, 512 полуходами в ветви и 256 главами. Превышения сообщаются ошибкой.
- Для FEN без подтверждённого дебютного пути может показываться «Без ECO». Приложение не придумывает отсутствующую историю.
- Новый визуальный граф не проходил отдельный повторный нагрузочный замер на тысячах партий. Результаты прежнего рендера не выдаются за измерения новой компоновки.
- Матрица размеров проверена с эмуляцией DPR 1.25, установленная версия — при фактическом DPR 1.25 в Windows. Другие системные масштабы отдельно не проверялись. Полный модуль Knowledge и дополнительные метрики не разрабатывались.
