# ChessPush — продуктовый интерфейс: отчёт реализации

18 октября 2026. Основание: CHESSPUSH_PRODUCT_UX_REDESIGN_TASK.md. Изменения выполнены в существующем Tauri/React/Rust приложении; работа проверена на изолированных данных.

## Что изменилось в работе пользователя

- **Главная → Продолжить** возвращает последнюю ветвь, партию с выбранным полуходом или репертуар. Рядом находятся последние партии и документы; часы и рейтинг занимают вторичное место.
- **Моя игра → Карта игры:** выбрать сторону → нажать крупный жетон хода либо сделать его на доске → получить следующий уровень продолжений. Наведение показывает одну стрелку. История сверху и «Назад по ветви» используют выбранный префикс. Глубина, FEN и камера не нужны для начала работы.
- **Продолжение → Партии → Открыть партию:** открывается фактический ход. Возврат восстанавливает ветвь и прокрутку. Подборка подтверждённых моментов открывает позицию перед событием; проверенная альтернатива показывается по запросу.
- **Репертуар на карте → существующий узел документа:** изменить комментарий/вариант → сохранить → «К ветви». Это тот же KnowledgeDocument с теми же ID. Самостоятельный раздел предлагает список, создание и импорт PGN.
- **Моя игра → Подробная статистика:** Дебюты, Качество, Время, Реализация и окончания, Все показатели. Методы, единицы, интервалы, профили и исходные партии остались доступны. Числовой дебютный срез открывает общую карту, отдельная дебютная доска удалена.
- **Библиотека:** Источник → Отбор → Получить партии. После обработки доступны сохранённые файлы, ограниченный список партий, нативный replay на доске и исходный PGN. Материал библиотеки не становится личной статистикой.
- **Настройки:** Аккаунт, Внешний вид, Движок, Диагностика. Браузерный вход основной; ручной токен и технические настройки движка раскрываются отдельно. Ошибки записи и доступа остаются видимыми.

Полное соответствие прежних действий новым маршрутам: [PRODUCT_UX_MIGRATION_MAP.md](PRODUCT_UX_MIGRATION_MAP.md).

## Карта и данные

Основной вид — доступные HTML-кнопки с официальными SVG-фигурами, контекстом и компактными превью. Первые продолжения видны без Fit/Pan. «Ещё» раскрывает только соседние продолжения и не меняет знаменатель. Доска имеет доступ ко всем известным ходам, включая скрытые в превью. Все варианты превращения сохраняются.

По умолчанию **«Эта ветвь»** отбирает реальные посещения после выбранного префикса. Режим всех порядков ходов явно меняет область агрегирования. Для продолжения из другого порядка выбирается действительное посещение; история из чужих рёбер не склеивается. Циклы представлены очередными посещениями. Уникальные партии и посещения раскрываются отдельно.

Репертуарный слой не меняет N, частоты и исходы практики. Различаются совпадение, неподготовленный сыгранный ход, несыгранная подготовка и отсутствие подготовленного ответа после репертуарного узла. Подготовленные ветви имеют подпись и пунктир; не получают фиктивные 0% результатов. При нескольких совпадениях доступен выбор адреса документа.

«Общая карта» — вторичный ограниченный обзор того же индекса, с явной подписью фрагмента и всех порядков ходов. Перетаскивание вершин отключено. Cytoscape загружается только при открытии обзора; локальная карта его не загружает.

Смена контекста блокирует устаревшие продолжения уже при render. Фоновое обновление той же ветви сохраняет кнопки, фокус и порядок; новый материал добавляется без перестановки существующих строк. Устаревшие async-ответы и старые подборки анализа не заменяют актуальное состояние. Адрес из редактора потребляется один раз, а не применяется заново при каждом открытии карты.

## Архитектура и сохранность

- Сохраняются общий PositionKey, GameOccurrence, VariationTree, KnowledgeDocument, первичные партии и оценки. Редактор репертуара не создаёт отдельного формата знаний.
- Расчёты, определения метрик, параметры Stockfish, eligibility и T0 не изменены. Новые исследовательские метрики не добавлены. Полноценные Knowledge/Training не имитируются пустыми активными разделами.
- Расширены существующие DTO графа: область префикса/транспозиций, превью, ссылки подтверждённых случаев с канонической позицией/ходом/ревизией, окончание репертуарного продолжения. Evidence привязан к той же выборке и конкретному посещению.
- Добавлены ограниченные read-only запросы последних пяти партий, контролей времени и страниц библиотеки по 20 записей. Они переиспользуют существующие Game/Replay и хранилище.
- Обзор/Партии/подборка карты запрашивают practice-проекцию того же снимка расчёта: полные исходы и краткие данные партий, выбранный профиль и превью подтверждённых событий. Глубокие аналитические структуры передаются только при явном открытии подробностей. UI различает practice/full; неполный ответ не используется как готовый подробный отчёт. Прежний API без view сохраняет полный контракт.
- **Миграций нет; user_version остаётся 7.** Идентификатор приложения и хранилище токенов не менялись. PGN, payloads, ID узлов и версии анализа не конвертировались.
- Сохраняемый адрес рабочего места, фильтры и черновики UI находятся в versioned localStorage; это не альтернативное хранилище шахматных фактов. Первичные документы и графовый индекс остаются в SQLite. При недоступности browser storage работа с нативными данными сохраняется, адрес продолжения может не сохраниться.
- Проверки не открывали пользовательскую БД и не изменяли установленную копию. [Проверка хешей](screens/product-ux/data-preservation.json) подтверждает неизменность фактических партий, исходных payloads, сохранённых анализов и T0 в тестовой копии после UI-проходов.

## Проверки

Подробная матрица 22 сценариев, UX01–UX17 и границ доказательства: [PRODUCT_UX_ACCEPTANCE.md](PRODUCT_UX_ACCEPTANCE.md). [Финальный GUI-повтор](screens/product-ux/evidence/final-gui-checks.json) фиксирует проверенный SHA256 сборки.

Фактически выполнены:

- production frontend/TypeScript и нативная Tauri debug-сборка — PASS; Vitest — 33 теста в 9 файлах;
- Rust — 189 PASS: 174 unit, 12 integration, три отдельных теста с настоящим Stockfish; Cargo fmt/Clippy с `-D warnings`, Prettier и privacy — PASS;
- native API → синхронизация → SQLite → GUI → настоящий Stockfish, три перезапуска, догрузка, дедупликация, неизменный T0, восстановление очереди и сохранение истории при отключении;
- native-карта: крупные продолжения, доска/клавиатура, транспозиции, повторение, подготовленный слой, точный viewer, неизвестный легальный ход, четыре превращения, reduced motion и восстановление после процесса;
- общий редактор: 9 GUI-сценариев, реальный конфликт ревизии, сохранение ввода при ошибке записи, черновик удалённого узла, ссылка на 400-й полуход, смысловой round-trip нескольких глав/RAV/NAG/рисунков;
- оболочка: две темы × 900×700/1440×960/1920×1080; отдельные native-снимки тех же размеров, переходы Home/viewer, общий редактор и библиотека;
- управляемые отрицательные состояния: нет аккаунта/истории/анализа, пустой фактический фильтр, offline, 429, истёкший доступ и диагностика. Подстановка на границе IPC явно отмечена; это не выдаётся за сетевой сбой;
- контраст выбранных текстовых токенов не ниже 4.5:1, интерактивных границ не ниже 3:1; это выборочная проверка, не полный аудит WCAG.

Команды и логи: [final-checks/summary.json](screens/product-ux/evidence/final-checks/summary.json). Выполнены `npm run tauri build -- --debug --no-bundle`, `npm test`, `npm run format:check`, `npm run check:privacy`; Cargo с `--manifest-path src-tauri/Cargo.toml`: `test --no-default-features`, `test --no-default-features -- --ignored --test-threads=1` с `CHESSPUSH_STOCKFISH`, `fmt --check`, `clippy --no-default-features --all-targets -- -D warnings`.

Финальный native-прогон той же версии на 1000 партиях: первый полезный экран карты — 2,13 с; первые/повторные 20 переходов — p95 driver total 322,5/319,2 мс. В эту величину входит около 195 мс ожидания драйвером стабильности перед кликом; максимум от настоящего клика до принятой проекции в основной серии — 86,5 мс, в дополнительной — 108,8 мс. Это не гарантия 100 мс и не измерение завершённой анимации. В интервале 40 шагов — 0 statistics_report и 0 longtasks. [Исходные 40 замеров и метод](screens/product-ux/evidence/native-performance.md).

В ходе проверки найден и исправлен поздний запуск полного отчёта после закрытия Обзора: ранее ответ 52,48 MB давал 332 мс разбора JSON. Отмена устаревшей загрузки проверена отдельно. Обычный Обзор теперь получает 657 798 байт и разбирает JSON за 4,0 мс. Явный переход к полным Результатам по-прежнему возвращает все данные: проверены график и 1006 непустых строк, затем возврат в ту же ветвь карты. ## Ограничения и последующая приёмка

- Проверка агентом подтверждает технические действия, но не заменяет исследование понятности человеком. Пять заданий для пользователя находятся в протоколе приёмки.
- Windows display scaling 125–150% не переключался. Проверены CSS viewport/DPR-эмуляции; их параметры сохранены. Полный screen-reader/WCAG-аудит не проводился.
- Скорость 1000 полностью проанализированных партий и гораздо больших графов не измерялась. Cold-расчёт Обзора по 1000 партиям в debug занял 10,46 с: practice-проекция уменьшает передачу, но пока переиспользует полный backend snapshot. Он выполняется вне UI-потока; карта его не ждёт.
- Явная полная аналитика остаётся тяжёлой: в том же прогоне 52,48 MB, 13,71 с до полезного экрана, longtasks 312 мс при разборе JSON и 93 мс при выводе 1006 строк. Дальнейшее разбиение вычислений и постраничная передача тематических отчётов остаются отдельной оптимизацией. Устранение всех блокировок приложения не заявляется.
- Общая карта показывает ограниченный фрагмент, а не все поздние позиции сразу. При отсутствии подходящих оценок подборка не утверждает отсутствие ошибок.
- O14/O15 и исследовательские показатели не объявляются готовыми из-за наличия редактора. Полный Knowledge, SRS, рекомендации и другие будущие модули не реализовывались.
- Во время разработки установленная пользовательская версия не использовалась для тестов. По отдельному последующему заданию установлен релиз alpha.5 с сохранением данных и обновлением ярлыков: [INSTALLATION_ALPHA5.md](INSTALLATION_ALPHA5.md).
