# ChessPush — описание текущего интерфейса

Дата фиксации: **17 октября 2026 года**. Версия приложения: **0.2.0-alpha.4**, Windows.

Документ описывает интерфейс существующей версии: структуру экранов, расположение областей, названия элементов, отображаемые данные, действия пользователя и состояния. Основание — текущие React-компоненты, стили, формирование данных для интерфейса и сохранённые снимки выполненных GUI-проверок. Это описание реализации, а не проект следующей версии. Оценки и предложения по изменению интерфейса в документ не включены.

Значения аккаунта, рейтингов, партий, путей файлов и результатов анализа зависят от пользовательских данных. Здесь описаны их места и форматы без персональных значений. Обозначения в фигурных скобках, например `{количество}`, обозначают переменные значения, а не буквальный текст приложения.

## 1. Окно и общая навигация

Приложение открывается в отдельном окне с заголовком **ChessPush**. Исходный размер окна в конфигурации — 1440 × 960, минимальный — 900 × 700. Используются системные элементы управления окном Windows.

Верхняя панель приложения занимает 80 px по высоте. Слева расположена текстовая надпись **ChessPush**, далее — горизонтальная навигация. Справа находится кнопка с контурной иконкой шестерёнки.

Порядок элементов навигации:

| Элемент    | Вид                                                                    | Что открывает                                                     |
| ---------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Главная    | Иконка дома; название доступно при наведении и для средств доступности | Часы и рейтинги подключённого аккаунта                            |
| Базы       | Текстовая кнопка                                                       | Доску и форму отбора/импорта PGN/ZST                              |
| Статистика | Текстовая кнопка                                                       | Раздел с семью внутренними вкладками                              |
| Знания     | Текстовая кнопка                                                       | Страницу с заголовком «Знания»                                    |
| Мои партии | Текстовая кнопка                                                       | Ту же область Statistics, открытую на внутренней вкладке «Партии» |
| Тренировка | Текстовая кнопка                                                       | Страницу с заголовком «Тренировка»                                |
| Настройки  | Иконка шестерёнки в правой части панели                                | Модальный диалог поверх текущего экрана                           |

Активный пункт основного меню выделен цветом акцента и нижней линией. При запуске выбран экран **Главная**. Надпись ChessPush не является кнопкой перехода.

«Настройки» не заменяют основную страницу: её содержимое остаётся под затемнённым фоном. Боковой панели навигации и отдельной нижней панели приложения нет.

## 2. Общее оформление и элементы

### 2.1. Темы

Есть две темы: **Светлая** и **Тёмная**. Исходное значение — светлая. Выбор находится в настройках и сохраняется между запусками.

| Роль цвета                             | Светлая тема       | Тёмная тема |
| -------------------------------------- | ------------------ | ----------- |
| Основной фон                           | `hsl(37 10% 92%)`  | `#161512`   |
| Верхняя часть фонового градиента       | `hsl(37 7% 85%)`   | `#24221e`   |
| Основная поверхность                   | `#ffffff`          | `#262421`   |
| Дополнительная поверхность             | `hsl(0 0% 96%)`    | `#302e2b`   |
| Основной текст                         | `hsl(0 0% 30%)`    | `#bababa`   |
| Вторичный текст                        | `hsl(0 0% 50%)`    | `#999999`   |
| Акцент                                 | `hsl(209 77% 46%)` | `#3692e7`   |
| Положительное/подготовленное состояние | `hsl(88 62% 37%)`  | `#629924`   |
| Предупреждающее состояние              | `hsl(37 100% 41%)` | `#d59120`   |
| Ошибка                                 | `hsl(0 60% 50%)`   | `#e46060`   |
| Границы                                | `hsl(0 0% 83%)`    | `#403d39`   |

Фон страницы содержит вертикальный градиент от верхнего цвета к основному. Цвета доски в обеих темах: светлые поля `#f0d9b5`, тёмные `#b58863`.

### 2.2. Текст и формы

Основной шрифт — Segoe UI, затем Noto Sans и системный sans-serif. Базовый размер текста — 15 px, межстрочный интервал — 1,45. Числа во многих таблицах и счётчиках используют цифры одинаковой ширины. FEN, PGN и технические данные в отдельных областях выводятся моноширинным шрифтом.

Логотип-название имеет размер 32 px и начертание 300; при ширине окна до 1100 px — 26 px. Заголовок Statistics — 28 px. Большинство заголовков второго уровня — 23 px. Подписи осей графиков — 13 px; подписи вершин графа — 12 px, рёбер — 11 px.

Поля ввода и списки имеют однотонный фон поверхности, рамку и радиус 3 px. Название поля обычно расположено над ним. Флажки — квадратные, с акцентным цветом. Основные кнопки имеют заливку цветом акцента и белый текст; другие кнопки преимущественно без заливки до наведения. Недоступные элементы отображаются с уменьшенной непрозрачностью. Кнопки и заголовки раскрывающихся блоков получают видимую рамку при клавиатурном фокусе.

Даты и числа форматируются по-русски. В Statistics даты и время представлены в часовом поясе Europe/Moscow; часы на главной используют локальное время компьютера. В названиях и данных одновременно встречаются русские подписи и обозначения PGN, FEN, ECO, Accuracy, Loss, CP, WDL, POV, Spent, ply.

### 2.3. Таблицы и раскрывающиеся блоки

Таблицы преимущественно занимают всю ширину своей области. Заголовки имеют фон дополнительной поверхности и вторичный цвет текста. Между строками есть горизонтальные границы. При наведении строка меняет фон. Широкие таблицы помещаются в области с горизонтальной прокруткой.

Раскрывающиеся блоки обозначены треугольником и названием. Они используются для дополнительных фильтров, подробностей метрик, исходных данных, случаев, очереди анализа и отдельных аналитических представлений. В одном раскрытом блоке могут находиться другие раскрывающиеся блоки.

Отсутствующее числовое значение обычно обозначается `—` либо текстовым статусом. Вычисленный ноль выводится числом. Размер выборки может отображаться как `N`, `n`, `известно/доступно`, число партий, решений или посещений.

### 2.4. Шахматная доска

Во всех текущих шахматных экранах используется Chessground с коричневой доской и SVG-фигурами Cburnett. Доска квадратная; координаты файлов находятся снизу, координаты горизонталей — справа внутри доски. Есть подсветка последнего хода, выбранной фигуры, допустимых полей и шаха.

На редактируемых досках ход выполняется перетаскиванием либо последовательными кликами по фигуре и целевому полю. Нелегальные ходы не принимаются. Анимация перемещения фигур имеет длительность 200 мс. При системном предпочтении уменьшенного движения анимация при обновлении доски отключается. Премувы выключены.

Правой кнопкой мыши рисуются стрелки и круги; модификаторы клавиатуры позволяют использовать зелёный, красный, синий и жёлтый цвета. Конкретное сохранение рисунков зависит от экрана: в репертуаре они являются редактируемыми аннотациями позиции, в остальных досках относятся к текущему сеансу просмотра.

При превращении пешки поверх доски открывается выбор фигуры: ферзь, конь, ладья, слон. Используются изображения фигур. Выбор появляется у поля превращения. Клик по фону выбора или Escape отменяет превращение.

## 3. Главная

Под верхним меню находится центральная область с часами и двумя областями рейтинга.

Вертикальный порядок:

1. Текущее время в формате `ЧЧ:ММ`.
2. Две области рейтинга: Rapid слева, Blitz справа.
3. Кнопки входа, если соединение с аккаунтом не подтверждено.
4. Сообщение об ошибке аккаунта, если оно есть.

Время показано шрифтом 80–112 px в зависимости от ширины. Цифры обновляются по системным часам. У каждого рейтинга есть шахматная иконка из шрифта Lichess; доступный рейтинг расположен под ней шрифтом 34 px. Слова Rapid и Blitz используются в доступных названиях областей; отдельной текстовой подписи категории под иконкой нет.

Если рейтинг больше 1900, под соответствующей областью появляется полоса продвижения к 2000. В ней отображается промежуток от 1900 до 2000; при значении 2000 и выше полоса заполнена целиком. При рейтинге 1900 и ниже полосы нет.

Состояния главной:

| Состояние                                       | Что показано                                                                        |
| ----------------------------------------------- | ----------------------------------------------------------------------------------- |
| Аккаунт подключён                               | Часы, иконки и доступные Rapid/Blitz; кнопка входа скрыта                           |
| Аккаунт не подключён                            | Часы, иконки категорий, кнопка «Войти через Lichess»; числовые рейтинги отсутствуют |
| Вход выполняется                                | Кнопка «Ожидание входа…»; в состоянии ожидания авторизации также «Отменить вход»    |
| Нет соединения                                  | Числовые рейтинги скрыты; остаются иконки и действие входа                          |
| Ошибка или недействительный токен               | Дополнительно показывается сообщение аккаунта                                       |
| Подключение есть, отдельный рейтинг отсутствует | У соответствующей категории остаётся иконка без числа                               |

Часы и рейтинги не являются переходами к другим экранам.

## 4. Настройки и подключение Lichess

### 4.1. Расположение диалога

Настройки открываются кнопкой-шестерёнкой из любой основной страницы. Это диалог шириной 430 px, с собственной вертикальной прокруткой и максимальной высотой 90% окна. Сзади — полупрозрачное затемнение.

Содержимое сверху вниз:

1. Заголовок **Настройки** и кнопка `×`.
2. Поле **Ник**.
3. Поле **Токен** и кнопка **Подключить** в одной строке.
4. Кнопка **Войти через Lichess** либо **Отменить вход**.
5. Список **Тема**.
6. Раздел **Stockfish**.
7. Кнопка **Отключить аккаунт**, когда сохранён доступ к аккаунту.
8. Сообщение об ошибке, если оно есть.

Диалог закрывается крестиком, кликом по затемнённому фону или Escape. Общей кнопки «Сохранить настройки» нет: тема применяется при выборе, доступ к аккаунту меняется соответствующими кнопками, настройки движка сохраняются отдельно.

### 4.2. Аккаунт

| Элемент             | Поведение                                                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Ник                 | Поле только для чтения; показывает имя проверенного аккаунта                                                              |
| Токен               | Поле типа password, символы скрыты; сохранённый токен в него не подставляется                                             |
| Подключить          | Отправляет введённый токен на проверку; недоступна при пустом поле или выполняющемся входе; поле очищается после отправки |
| Войти через Lichess | Открывает авторизацию в системном браузере; после завершения приложение обновляет состояние аккаунта                      |
| Отменить вход       | Отменяет текущую попытку входа через браузер                                                                              |
| Отключить аккаунт   | Удаляет локально сохранённый доступ; недоступна во время операции аккаунта                                                |

Состояния ошибки отображаются текстом внутри диалога. Ошибка аккаунта, возникшая вне открытых настроек, может появляться в отдельном уведомлении внизу окна с крестиком закрытия.

### 4.3. Stockfish

Раздел находится непосредственно внутри настроек, отделён верхней линией и заголовком **Stockfish**.

| Поле или действие       | Тип, значения и исходное состояние                                       |
| ----------------------- | ------------------------------------------------------------------------ |
| Исполняемый файл        | Текстовое поле пути; рядом кнопка `…` для системного выбора файла        |
| Потоки                  | Числовое поле, 1–128; исходно 1                                          |
| Hash, MiB               | Числовое поле, 16–4096; исходно 128                                      |
| Режим                   | Список «Быстрый», «Стандартный», «Углублённый»; исходно «Стандартный»    |
| Лимиты анализа и Syzygy | Изначально свёрнутый блок                                                |
| Узлы                    | Внутри блока: необязательное число 100–2 000 000 000                     |
| На поиск, мс            | Внутри блока: необязательное число 10–300 000                            |
| Каталог Syzygy          | Внутри блока: путь и кнопка `…` выбора каталога                          |
| Проверить движок        | Проверяет заданную конфигурацию; недоступна без пути и во время операции |
| Сохранить движок        | Сохраняет конфигурацию; недоступна во время операции                     |

Пустые пользовательские лимиты означают использование лимитов выбранного режима. При смене режима пользовательские лимиты узлов и времени очищаются. После проверки или сохранения под кнопками появляется строка результата; при ошибке — текст ошибки.

## 5. Базы: доска, поиск и импорт партий

### 5.1. Компоновка

Экран разделён на две колонки. Слева — выбор дебюта, доска, управление доской и запись ходов. Справа — панель источника и парсера с вкладками **Фильтры** и **Файлы**.

Размер левой колонки связан с высотой окна; справа находится панель шириной 330–420 px. Панель парсера имеет фон поверхности, внутренние отступы, скругление и тень. При ширине окна до 1100 px отступы между областями уменьшаются.

### 5.2. Выбор дебюта и доска

Над доской находится поле **Найти дебют**. Ввод текста открывает выпадающий прокручиваемый список совпадений по ECO и названию. Поиск учитывает все введённые слова. Одновременно выводится до 60 результатов. В строке результата — ECO и название дебюта.

Выбор результата загружает его последовательность ходов на доску. Выбранные ECO и название становятся текстом-заполнителем поля поиска после очистки поисковой строки. Пользователь также может вручную сделать ходы на доске.

Под доской, слева направо:

| Видимая кнопка | Название/действие                                      |
| -------------- | ------------------------------------------------------ |
| `⇅`            | Перевернуть доску; подсказка «Перевернуть доску (F)»   |
| `⏮`            | В начало: стандартная или загруженная исходная позиция |
| `‹`            | Назад на один полуход                                  |
| `›`            | Вперёд на один полуход                                 |
| `⏭`            | В конец имеющейся линии                                |
| `⌫`            | Очистить стрелки текущей позиции                       |
| `↺`            | Сбросить доску к стандартной позиции                   |
| PGN            | Открыть диалог текста текущей линии                    |
| FEN            | Открыть диалог текущей позиции                         |

Ниже находится прокручиваемая запись ходов. Каждый ход — кнопка перехода к соответствующей позиции. Текущий ход выделен фоном. Если пользователь возвращается назад и делает другой ход, последующая линия доски заменяется новой; это поле последовательности, а не редактор дерева репертуара.

Последовательность до текущего положения курсора используется как дебютный префикс поиска в выбранном файле. Загрузка произвольной FEN изменяет доску; попытка выполнить дебютный поиск при нестандартной исходной позиции показывает «Для поиска по дебюту нужна стандартная начальная позиция».

### 5.3. Диалоги PGN и FEN

Оба открываются поверх экрана с затемнением и заголовком **PGN** или **FEN**. Ширина — до 700 px, текстовое поле высотой 200 px с возможностью увеличения по вертикали.

Содержимое: заголовок, крестик, редактируемое многострочное поле, место сообщения об ошибке, кнопка **Применить**. Крестик и клик по фону закрывают диалог. Применение корректного текста закрывает его и обновляет доску. Ошибка остаётся в открытом диалоге. Для PGN доска загружает основную линию; дерево RAV в этом диалоге не отображается.

### 5.4. Источник

Вверху правой колонки — кнопка **Выбрать PGN / ZST**. После выбора она показывает имя файла; полный путь доступен при наведении. Кнопка открывает системный диалог выбора одного `.pgn` или `.zst` файла. Источник регистрируется в списке файлов.

Во время обработки выбор нового источника недоступен. На этом экране нет отдельного заголовка первого уровня над двумя колонками.

### 5.5. Вкладка «Фильтры»

Поля сгруппированы в парные строки.

| Подпись    | Значения                                                        | Исходное значение |

| До         | Число 0–4000                                                    | 4000              |

Далее расположен изначально свёрнутый блок **Дополнительно**:

| --------------------------- | --------------------------------------------------------------------------------------------------------- |
| Разный рейтинг сторон       | Флажок, исходно выключен. Меняет подпись «Рейтинг от» на «Белые от» и добавляет отдельную пару для чёрных |

Внизу формы — кнопка **Найти партии** на всю ширину панели. Она доступна после выбора источника и готовности приложения к обработке. На время выполнения поля фильтров блокируются, а кнопка заменяется на **Остановить**. После запроса остановки её текст меняется на **Отмена…**, повторное нажатие недоступно.

### 5.6. Вкладка «Файлы»

Сверху — кнопка **Импорт PGN**, открывающая выбор `.pgn`. Этот путь запускает импорт без отбора по текущей форме фильтров.

Ниже — прокручиваемая история файлов. У каждой строки есть:

- имя файла; полный путь доступен при наведении;
- число связанных партий под именем, если оно больше нуля;
- кнопка `↗` с подсказкой **Выбрать источник**.

Нажатие на имя показывает файл в Проводнике. Кнопка `↗` выбирает его источником и возвращает панель к «Фильтрам». Список содержит зарегистрированные источники и файлы результатов. Пустой список не заменяется отдельной текстовой инструкцией.

### 5.7. Состояние выполнения

При выполнении или наличии результата под содержимым правой панели выводится блок операции:

- неопределённая полоса прогресса **Чтение базы** во время работы;
- счётчик **Обработано**;
- счётчик **Найдено**;
- после выполнения — **Готово**, **Остановлено** либо **Завершено с ошибкой**, затем длительность в секундах;
- имя полученного файла, если файл создан; нажатие показывает его в Проводнике.

Процент выполнения не выводится. Ошибка или предупреждение расположены ниже, имеют цвет ошибки и кнопку `×`. Остановка сохраняет уже завершённую часть результата.

## 6. Статистика: общая оболочка

### 6.1. Компоновка и вкладки

Область Statistics находится под верхним меню, ограничена максимальной шириной 1540 px и имеет вертикальную прокрутку страницы.

Сверху — заголовок **Статистика**. Справа от него — **Сравнить периоды** и **Синхронизировать**.

Ниже расположены внутренние вкладки в таком порядке:

1. **Обзор**.
2. **Дебюты**.
3. **Граф партий**.
4. **Качество игры**.
5. **Время**.
6. **Реализация и эндшпиль**.
7. **Партии**.

Активная вкладка отмечена цветом и нижней линией. Лента вкладок допускает горизонтальную прокрутку. Обычно ниже следуют фильтры, статусы и содержимое выбранной вкладки. Открытая конкретная партия временно заменяет содержимое вкладки, сохраняя общую оболочку Statistics.

### 6.2. Общие фильтры

Первая строка фильтров присутствует на всех вкладках, включая граф:

| Подпись  | Тип и варианты                                                                            |
| -------- | ----------------------------------------------------------------------------------------- |
| Аккаунт  | Список сохранённых наблюдаемых аккаунтов по никам                                         |
| С        | Начальная дата периода, поле с календарём                                                 |
| По       | Конечная дата периода, поле с календарём; выбранный день включён                          |
| Контроль | «Все» и доступные точные контроли вида `600+2`, в секундах основного времени и инкремента |
| Цвет     | Оба, Белые, Чёрные                                                                        |
| Фильтры  | Раскрывает дополнительную панель полей                                                    |

Исходно даты и контроль не ограничены, цвет — оба, вариант — обычные шахматы. Смена аккаунта сбрасывает остальные фильтры к этому исходному набору.

Дополнительные поля находятся во всплывающей двухколоночной панели **Фильтры**:

| Подпись               | Значения                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| Категория             | Все, Ультрапуля, Пуля, Блиц, Рапид, Классика, По переписке                                           |
| Фаза                  | Все, Дебют, Миттельшпиль, Эндшпиль                                                                   |
| Дебют                 | Текстовое поле                                                                                       |
| Рейтинг от            | Минимальный рейтинг соперника, числовое поле                                                         |
| Рейтинг до            | Максимальный рейтинг соперника, числовое поле                                                        |
| Партии                | Все, Рейтинговые, Нерейтинговые                                                                      |
| Источник              | Все, Lichess                                                                                         |
| Вариант               | Обычные шахматы, Все                                                                                 |
| Пограничные партии T0 | Флажок включения партий с неопределённостью относительно момента начала наблюдения; исходно выключен |
| Сбросить фильтры      | Оставляет текущий аккаунт и обычные шахматы, снимает остальные ограничения                           |

Отдельные строки выбранной области появляются при переходах из аналитики:

- название дебюта и кнопка **Все дебюты**;
- путь выбранной дебютной ветви и **Все ветви**;
- **Выбрано партий: {количество}** и **Снять выборку**.

Эти ограничения входят в общую выборку; переход к списку партий из показателя не открывает отдельное окно.

### 6.3. Строка синхронизации

Под фильтрами выводятся доступные элементы:

- **Обновление статистики…** во время пересчёта;
- **Наблюдение с {дата и время}**;
- **Синхронизация: {состояние} · {последняя успешная проверка}**;
- **Ожидают сверки: {число} · Незакрытые диапазоны: {число}**;
- **Граница T0: неполное подтверждение**, когда такое состояние сохранено;
- ошибка синхронизации и время следующего повтора, если они заданы.

Кнопка **Синхронизировать** запрашивает проверку новых партий. Она недоступна без подтверждённого подключения, во время операции аккаунта и при просмотре аккаунта, отличного от текущего активного подключения.

### 6.4. Покрытие и профиль анализа

На аналитических вкладках, кроме графа и открытого просмотрщика партии, над основным содержимым есть строка:

`{партий} партий · {с анализом}/{всего} решений с анализом · Вне выборки: {число}`.

При выполняющейся движковой задаче рядом показывается **Анализ: {прогресс}/{всего}**, при паузе — **Анализ: пауза**. Справа — список **Профиль статистики**. В нём есть **Последний совместимый профиль** и сохранённые конфигурации анализа с подписями из данных. При отсутствии человекочитаемой подписи может отображаться сокращённый идентификатор профиля. Полная подпись доступна при наведении.

### 6.5. Сравнение периодов

Кнопка **Сравнить периоды** показывает или скрывает дополнительную секцию над содержимым вкладки. При включении кнопка выделена.

Секция содержит заголовок **Сравнение периодов**, поля **Период B с** и **Период B по**, а также таблицу сравнения. Период A определяется основными датами Statistics. Строки включают покрытие общих условий и разницы показателей двух периодов; состояние может сообщать об отсутствии общих условий, пересечении периодов или недостатке данных. Для заполнения сравнительных данных требуются обе границы периода B.

### 6.6. Общий вид таблицы метрик

Таблицы показателей имеют столбцы:

| Столбец       | Содержимое и действие                                                                 |
| ------------- | ------------------------------------------------------------------------------------- |
| Показатель    | Название-кнопка, открывающее определение                                              |
| Значение      | Число и единица либо текстовый статус; статус может также стоять под имеющимся числом |
| N / доступно  | Размер использованной выборки и число доступных случаев                               |
| 95% интервал  | Нижняя и верхняя границы через многоточие либо `—`                                    |
| Без заголовка | Кнопка «Партии», переводящая к связанным партиям; недоступна без связанных ID         |

Диалог определения содержит название показателя, текст определения и пары **Единицы**, **Выборка**, **Метод**. Метод может быть представлен техническим идентификатором. Диалог закрывается крестиком или кликом по фону.

### 6.7. Начальные и пустые состояния

Если наблюдаемых аккаунтов нет, на вкладках, кроме графа, в основной области расположена кнопка **Подключить Lichess**. Лента вкладок и шапка Statistics остаются видимыми. Граф можно открыть и без наблюдаемого аккаунта, в том числе для работы с репертуаром.

При пустой выборке обычные аналитические представления сопровождаются текстом **Нет партий в выбранном периоде**. При загрузке — **Загрузка**. Без движковых оценок базовые данные остаются доступны, а соответствующие значения имеют прочерк или статус. Ошибки Statistics показываются строкой с кнопкой **Повторить**.

В браузерном запуске frontend вместо native-статистики выводится **Статистика доступна в приложении ChessPush**.

## 7. Статистика: Обзор

Содержимое расположено вертикально в следующем порядке.

### 7.1. Основные показатели

Первая таблица использует общий формат метрик и содержит пять строк:

1. **Набранные очки**, %.
2. **Потеря ожидаемого очка**, п.п.
3. **Выход из дебюта · ожидаемое очко**, %.
4. **Использовано возможностей**, %.
5. **Реализация преимущества**, %.

Название каждой строки открывает определение; справа доступен переход к партиям.

### 7.2. Динамика

Ниже — заголовок **Динамика** и список **Показатель динамики**:

- **Партии, шт.**
- **Набранные очки, %** — исходный выбор.
- **Рейтинг**.
- **Потеря q, п.п.**
- **Accuracy, %**.
- **Время, с**.

Отдельный список **Окно динамики**: **День**, **Неделя** — исходный выбор, **Месяц**, **Последние 50 партий**.

График содержит сетку, числовую вертикальную шкалу, временную горизонтальную шкалу, линии и точки. Разные условия представлены отдельными сериями; их названия указаны под графиком. При отсутствии значения линия прерывается. Для очков и Accuracy вертикальная шкала составляет 0–100. Для рейтинга нижняя граница зависит от имеющихся значений; для других величин начинается с нуля.

При наведении на точку появляется дата, значение, число партий и условия. Клик по точке переводит к партиям соответствующего окна. Точки доступны с клавиатуры: Enter или пробел выполняют тот же переход. При отсутствии точек выводится **Нет данных графика**.

### 7.3. Результаты по группам

Следующая таблица имеет столбцы **Группа**, **N**, **W / D / L**, **Очки, %**, **Loss, п.п.**, **Решений с анализом**.

Строки группируют партии по цвету, рейтинговому статусу, источнику/категории/точному контролю, варианту шахмат, способу завершения и разнице рейтингов. В результатах также могут присутствовать группы по порядку партии в наблюдаемой сессии. Название группы переводит к соответствующим партиям.

### 7.4. Игровые сессии

Изначально свёрнутый блок **Игровые сессии** содержит список **Разрыв, мин** с вариантами **15**, **30**, **60**; исходно 30.

Таблица: **Начало**, **N**, **W/D/L**, **Очки, %**, **Достоверный интервал, с**, **Между началами, с**, **Порядок**, действие **Партии**. В столбце порядка встречаются **Неоднозначен**, **Пересечение**, **Наблюдаемый**. Дополнительные записи загружаются кнопкой **Ещё случаи**.

### 7.5. Серии результатов

Свёрнутый блок **Серии результатов ({число})**. Таблица: **Исход**, **Длина**, **Период**, **Условия**, действие **Партии**. Исход представлен как «Победы» или «Поражения», период — две даты и время. Есть загрузка следующих случаев.

### 7.6. Сопоставимые позиции и периоды

При наличии соответствующих результатов доступен свёрнутый блок **Сопоставимые позиции и периоды** с таблицей **Прогресс в сопоставимых условиях**. Столбцы: **ID**, **Условие**, **A**, **B**, **Δ A−B**, **N A / B**, **95% интервал**, **Состояние**, действия **Случаи** и **Партии**.

### 7.7. Результаты и рейтинг

Завершающая таблица общего формата содержит остальные показатели группы G. Состав строк зависит от имеющихся рейтинговых шкал и данных. В неё входят:

- количество партий и процент побед;
- рейтинг соперников: медиана, среднее, P25, P75, IQR, доля без рейтинга и доля предварительных рейтингов;
- длина партии: медиана, P25, P75, IQR в полуходах;
- интервал от начала до последнего хода и подтверждённая длительность партии, когда эти данные доступны;
- число дней с партиями, дни наблюдения в периоде, доля дней с партиями и партий на активный день;
- отдельные рейтинговые показатели по каждой платформе/категории/варианту;
- условный Elo-перформанс и очки относительно Elo-базы;
- минимум и максимум наблюдаемого рейтинга, изменение рейтинга относительно T0;
- разница очков за белых и чёрных;
- число наблюдаемых сессий при разрывах 15/30/60 минут;
- максимальные серии побед и поражений.

Для строк с несколькими рейтинговыми шкалами в названии присутствует соответствующая шкала. Там, где значение не определено, выводится статус, например **разные рейтинговые шкалы**, **нет конечного значения перформанса** или **неоднозначный снимок T0**.

## 8. Статистика: Дебюты

### 8.1. Дополнительные органы управления

Под общей областью Statistics располагаются:

- список **Семейство** — «Все» и семейства из текущего отчёта;
- список **Ходы** — **Все**, **Собственные**, **Ответы соперников**;
- переключатели **По позиции** и **По линии**.

В режиме «По позиции» одинаковые позиции из разных последовательностей объединяются. В режиме «По линии» учитывается конкретная последовательность ходов. Эти переключатели относятся к дебютному дереву на данной вкладке.

### 8.2. Доска и продолжения

Рабочая область разделена на доску слева и панель продолжений справа. Под доской — **В начало**, **Назад**, **Перевернуть**. Назад недоступна в корне. На доске можно делать легальные ходы, изменяя выбранную линию дерева, в том числе к позиции без наблюдавшихся партий.

Справа находятся заголовок **Продолжения**, раскрываемые **Оценки позиции**, счётчики `{партий} партий · {посещений} посещений · {путей} путей`, затем последовательность в UCI либо текст **Начальная позиция**.

Таблица **Дерево продолжений**:

| Столбец        | Содержимое                                         |
| -------------- | -------------------------------------------------- |
| Ход            | SAN-кнопка перехода в следующую позицию            |
| Автор          | Свой, Соперник или Оба                             |
| N / посещения  | Уникальные партии и число посещений                |
| Loss, п.п. · n | Средняя потеря и число пригодных решений           |
| Доля, %        | Частота продолжения                                |
| Время, с · N   | Медиана времени и число доступных наблюдений часов |
| Очки, %        | Набранные очки в связанных партиях                 |
| Без заголовка  | «Партии», «Качество и часы», «Случаи»              |

Ниже могут находиться блок **Легальные ходы без партий ({количество})** с кнопками ходов и кнопка **Партии позиции**. У последней нет доступного действия, если связанных партий нет.

### 8.3. Оценки позиции и Syzygy

Блок **Оценки позиции · {пригодно}/{всего} контекстов** содержит таблицу **Контексты позиции**: **q, доля**, **CP / мат за белых**, **W / D / L за белых, ‰**, **POV для q**, **Состояние**, а также случаи перехода к партиям.

При наличии табличных данных в строке есть раскрытие **Syzygy · WDL {число} / DTZ {число}**. Внутри: **WDL, POV белых**, **DTZ, POV белых**, **Правило 50 ходов**, **Точность DTZ**, **Состояние**, **Набор таблиц**, **Контекст правил**. Последние поля могут содержать технические идентификаторы. Правило 50 ходов отмечается как «Учтено»/«Не учтено», DTZ — «Округлён»/«Без округления» либо прочерком.

### 8.4. Дебютные варианты

Под рабочей областью находится таблица **Дебютные варианты**: **ECO**, **Вариант**, **N**, **W / D / L**, **Очки, %**, **95% интервал очков**, **Рейтинг соперников**, **Loss, п.п.**, **Выход q**, действие **Партии**.

Название варианта — кнопка установки фильтра. В рейтинге соперников также показан размер выборки; рядом с выходом q — число пригодных наблюдений. Далее следует общая таблица **Показатели дебютов**, содержащая имеющиеся метрики группы O, в том числе **Выход из дебюта · ожидаемое очко**.

### 8.5. Дебюты, варианты и подварианты

Изначально раскрытый блок **Дебюты, варианты и подварианты ({количество})** содержит таблицу **Иерархия дебютов**. Вложенность ветвей передаётся отступами в первом столбце.

Столбцы: **Ветвь**, **Цвет**, **N / доля, %**, **W / D / L**, **Очки, %**, **ΔR, медиана · N**, **Loss, п.п. · n**, **ACPL**, **Accuracy**, **≥10 п.п. /100**, **Spent, с**, действия.

Название ветви устанавливает фильтр ветви и её цвета. Действия строки: **Партии**, **Случаи**, **Качество и часы**; при заданном периоде B также **Периоды** с таблицей сравнения ветви и деталями предыдущего периода. Исходно показано до 80 ветвей; далее доступна кнопка **Ещё 100 ветвей**.

### 8.6. Качество и часы

Общий вложенный блок **Качество и часы · {количество} решений** используется у ветвей и продолжений. Таблица имеет столбцы **Показатель**, **Значение**, **Известно / решений** и строки:

- **Lq, среднее / медиана / P90, п.п.**
- **ACPL, сантипешки**.
- **Accuracy, гармоническое, %**.
- **Lq ≥10 п.п., случаев / на 100 решений**.
- **Известный расход, сумма, с**.
- **Расход на решение, медиана, с**.
- **Известный расход на партию, среднее, с**.
- **Покрытие часов, %**.

Далее — раскрытие **Решения ветви** со списком случаев и **Часы по партиям ({количество})**. Последняя таблица содержит **Партия**, **Известная сумма, с**, **Известно / решений**, **Покрытие, %**, затем вложенные **Решения партии**. Исходно показано до 30 партий, следующая порция — **Ещё 100 партий**.

### 8.7. Выход из дебюта

Свёрнутый блок **Выход из дебюта** включает вложенные блоки **Граница фаз**, **Последняя именованная позиция**, **Срез 20 ply**. В заголовке каждого — размер пригодной выборки и среднее q.

Таблицы: **Партия**, **Ply**, **CP / мат**, **q, доля**, **POV**, **Состояние**, **Позиция**. Кнопка позиции открывает связанную партию на соответствующем ходе. При отсутствии ссылки она недоступна.

### 8.8. Первая существенная потеря

Свёрнутый блок **Первая существенная потеря · N={количество} партий**. Таблица: **Партия**, **Ход**, **Loss, п.п.**, **Анализ, n**, **Состояние**, **Позиция до решения**. Статус различает подтверждённую первую потерю, первое наблюдаемое событие при неполном анализе и отсутствие найденных потерь. Можно загрузить следующие случаи.

### 8.9. Ответы соперника

Свёрнутый блок **Ответы соперника: следующие 3 решения**. Внутри флажок **Повторявшиеся ответы**, исходно выключенный.

Таблица **Трудные ответы соперника**: **Ответ**, **Посещения / игры**, **Доля, %**, **Полные / исключённые окна**, **Loss, п.п.**, **≥10 п.п. /100**, раскрытия **Ответы** и **Окна решений**. Эти раскрытия ведут к исходным позициям. Для дополнительных строк есть **Ещё 100 ответов**.

### 8.10. Изменение дебютных показателей

При заданных обеих датах периода B появляется раскрытый блок **Изменение дебютных показателей**. Он содержит таблицу метрик **Динамика дебютов** и таблицу **Динамика продолжений**: **Ход**, **Доля A, %**, **Доля B, %**, **Δ, п.п.**, **Новые / повторные пути**, **Впервые в истории**, действия **Случаи** и **Периоды и пути**.

Внутри **Периоды и пути** есть строки посещений, доли выбора, изменения доли, новых и повторных путей, путей без достоверной даты и первого сохранённого появления. Есть **Открыть**, **Посещения в предыдущем периоде** и таблица **Сравнение качества продолжения** со столбцами **Показатель**, **Δ**, **Единицы**, **Текущий / предыдущий N**, **Состояние**.

На этой вкладке существует отдельное раскрытие **Репертуар** с таблицей **Зависимости репертуара**. В строках выводятся ID **O14**, **O15**, состояние **нужен внешний источник** и текст зависимости.

Это содержимое данного аналитического раскрытия. Выбор, наложение и редактирование существующих репертуаров находятся на вкладке **Граф партий**, описанной далее.

Ниже — заголовок и таблица **Потери в дебюте**: **Позиция**, **Ход**, **N / партии**, **Средняя потеря, п.п.**, **Сумма, п.п.**, **Время, с**, действия.

## 9. Статистика: Граф партий

### 9.1. Общая компоновка

Граф располагается внутри Statistics, под общими фильтрами и строкой синхронизации. Его содержимое сверху вниз:

1. Панель навигации и поиска позиции.
2. Панель репертуарного слоя.
3. Строка количества партий, позиций и посещений.
4. Две колонки: доска слева, граф справа.
5. Горизонтальная строка данных выбранной позиции.
6. Таблица продолжений и таблица путей к позиции.

На широком окне доска занимает до 560 px, граф — оставшуюся ширину. Высота полотна графа — 540 px. При ширине до 1200 px высота полотна — 450 px, а две нижние таблицы располагаются друг под другом. Полотно графа имеет фон дополнительной поверхности.

### 9.2. Панель навигации

| Элемент       | Действие                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------ |
| Обзор         | Переход к стандартной начальной позиции                                                    |
| `←`           | Предыдущая запись истории навигации по графу; недоступна в начале истории                  |
| `→`           | Следующая запись истории; недоступна в конце                                               |
| Вписать граф  | Изменение масштаба и положения так, чтобы отображаемый фрагмент поместился на полотне      |
| Фокус позиции | Центрирование выбранной вершины                                                            |
| Глубина       | Список от 1 до 5; исходно 2                                                                |
| FEN           | Текстовое поле поиска/открытия позиции                                                     |
| Найти позицию | Переход к введённой FEN; недоступна при пустом поле. Enter в поле выполняет то же действие |

Стрелки истории возвращают к посещённым состояниям навигации, а не обязательно отменяют один шахматный полуход. Переход на один из ранее сыгранных ходов также доступен в строке пути под доской.

### 9.3. Репертуарный слой

Во второй строке находятся:

- флажок **Репертуар**, исходно включённый;
- список выбора репертуара; исходный пункт **Не выбран**;
- **Создать репертуар**;
- **Редактировать репертуар**, недоступная без выбранного документа.

В списке у документа выводятся его название и сторона: **Белые**, **Чёрные** или **Оба цвета**. Одновременно в этом списке выбирается один репертуар. Выключение флажка убирает его наложение на граф, но не удаляет документ.

Создание открывает редактор репертуара с выбранной на графе позицией в качестве исходной FEN. С документом сохраняется связь с позицией, а при наличии выбранного фактического посещения — и с ним. Редактирование открывает выбранный документ. После сохранения созданный или отредактированный репертуар выбирается для наложения.

### 9.4. Счётчики и отображение графа

Строка состояния имеет вид:

`{число} партий · {число} позиций · {число} посещений`.

Во время получения данных вместо неё выводится **Обновление графа…**. При ошибке появляется сообщение и **Повторить**.

Вершина — прямоугольник со скруглёнными углами. Внутри отображаются:

- название входящего хода либо **Позиция**;
- `N={уникальных партий} · {число} посещ.`;
- число побед/ничьих/поражений;
- при наличии скрытых продолжений — `+{число}`.

Выбранная вершина имеет рамку акцентного цвета толщиной 3 px. Рёбра направлены стрелками. На ребре расположен SAN хода и, при наличии наблюдений, процент его выбора. Толщина ребра зависит от числа посещений. Повторения и транспозиции могут образовывать общие вершины и циклы.

Легенда под графом:

| Подпись        | Представление                |
| -------------- | ---------------------------- |
| Сыграно        | Обычная сплошная линия       |
| Подготовлено   | Зелёная пунктирная линия     |
| Совпадение     | Зелёная сплошная линия       |
| Вне репертуара | Линия предупреждающего цвета |

Рёбра текущего пути дополнительно выделяются акцентным цветом. Числа фактически сыгранных партий и результатов относятся к наблюдавшимся партиям. Подготовленные продолжения без наблюдений могут иметь нулевое число партий и посещений, а долю и результат — прочерк.

Масштаб меняется колёсиком мыши, полотно перемещается перетаскиванием свободного пространства. Вершины на полотне допускают перетаскивание. Клик по вершине или ребру выбирает соответствующую позицию и обновляет доску. Если позиция достигалась несколькими путями, конкретное посещение можно выбрать в таблице путей.

При смене выбранной позиции камера центрирует её с анимацией 240 мс. Новые элементы появляются с анимацией прозрачности 180 мс. При системном уменьшении движения эти анимации отключены. Обычное обновление данных сохраняет текущее положение камеры, пока не запрошены фокус или вписывание.

### 9.5. Ограничение отображаемого фрагмента

На полотне показывается ограниченный фрагмент графа: исходно глубина 2 и до 5 отбираемых продолжений на узел; запрос ограничен 200 вершинами. Эти ограничения не являются количеством сохранённых партий.

При наличии неотображённых элементов под графом есть **Ещё ветви (+{число})**. Кнопка увеличивает число отбираемых продолжений на 5, до 30, и глубину на 1, до 5. Под таблицей продолжений может быть **Раскрыть на графе (+{число})**, увеличивающая число продолжений; при достижении 30 она недоступна.

При отсутствии подтверждённых партий выводится **Нет подтверждённых партий в выборке**. При этом доступ к репертуару и его подготовленным продолжениям сохраняется.

### 9.6. Доска и путь

Доска показывает выбранную позицию. На ней разрешены ходы из доступных продолжений этой позиции — наблюдавшихся или подготовленных в выбранном слое. Ход на доске выполняет переход графа, не редактирует сыгранную партию и сам по себе не добавляет вариант в репертуар.

На доске автоматически показаны стрелки первых десяти продолжений. Подготовленные отмечаются зелёным, собственные отклонения — жёлтым, остальные — синим. Толщина связана с частотой продолжения. Во время загрузки перемещение фигур недоступно.

Под доской — строка **Путь графа**: кнопка **Начало**, затем кнопки SAN каждого полухода выбранного пути. Текущий последний ход выделен. Нажатие на предыдущий ход возвращает к соответствующему префиксу. Ниже — **Перевернуть доску**.

### 9.7. Выбранная позиция

Под доской и графом находится строка между горизонтальными границами:

- **Выбранная позиция**;
- `N={число} · Посещений: {число}`;
- `В/Н/П: {победы}/{ничьи}/{поражения}`;
- **Очки: {значение}%**;
- при наличии оценки — **Stockfish (белые): {оценка или мат} · глубина {число} · профиль {ID} · N={покрытие}**;
- дата и время первого и последнего наблюдений.

Оценка выражается в пешках либо как `#{матовая оценка}`. Идентификатор профиля в этой строке может выводиться непосредственно текстом.

### 9.8. Продолжения графа

Таблица имеет столбцы:

| Столбец      | Содержимое                                               |
| ------------ | -------------------------------------------------------- |
| Ход          | SAN-кнопка перехода и кнопка `≡`                         |
| N            | Уникальные партии                                        |
| Посещ.       | Число посещений ребра                                    |
| Частота, %   | Доля наблюдавшегося продолжения                          |
| В/Н/П        | Победы, ничьи, поражения                                 |
| Очки, %      | Результативность связанных партий                        |
| Время, с / N | Средний известный расход и число наблюдений часов        |
| Репертуар    | Состояние продолжения относительно выбранного репертуара |

Кнопка `≡`, доступное название **Партии хода {SAN}**, ограничивает правую таблицу посещениями выбранного хода. Повторное нажатие снимает это ограничение.

В репертуарном столбце используются **Подготовлено**, **Совпадение**, **Вне репертуара**, **Ответ без подготовки**, **Нет продолжения**, **Сыграно**. «Подготовлено» и «Совпадение» — кнопки открытия редактора на связанной главе и конкретном узле.

### 9.9. Пути к позиции

Правая таблица озаглавлена **Пути к позиции · {количество}**. Её столбцы: **Партия**, **Результат**, **Ход**, **Путь**.

- **Партия**: кнопка с именами белых и чёрных, открывает просмотр сыгранной партии на соответствующем полуходе.
- **Результат**: результат партии.
- **Ход**: номер полухода и ревизия в формате `{ply} · r{ревизия}`.
- **Путь**: кнопка **Выбрать путь**, переводящая граф к конкретному посещению позиции.

Повторные посещения одной позиции в одной партии представлены отдельными записями. Дополнительные записи загружаются кнопкой **Ещё партии**. Если сохранённая ссылка относится к другой ревизии партии, интерфейс показывает сообщение с номерами сохранённой и актуальной ревизий.

## 10. Статистика: Качество игры

### 10.1. Таблица «Качество решений»

Первой показана общая таблица метрик. Она включает строки групп Q, показатели достигнутых фаз S01 и показатели прогресса/покрытия P. Строки зависят от текущих данных и выбранного профиля.

Представлены следующие семейства показателей:

- **ACPL** и отдельная серия **ACPL · capped adjacent**;
- **Потеря ожидаемого очка**, её медиана и P90;
- **Потеря Lichess WinPercent** и её медиана;
- **Покрытие WDL по позициям**;
- **Accuracy хода · среднее**, **Accuracy партии · среднее**, **Accuracy · группа Insights**;
- число неточностей, ошибок и зевков и их частота в классификации Lichess Advice;
- число и частота потерь не менее 5, 10 и 20 п.п.;
- сумма существенных потерь и медиана существенной потери;
- существенные потери при наличии выбора и при единственном легальном ходе;
- **Сохранено приемлемое состояние**;
- показатели распределения и серий потерь, включая средние игровые P90, максимум, IQR, стандартное отклонение и окно трёх решений, с отдельными срезами по наличию выбора;
- достигнутые фазы, их длина и покрытие;
- сопоставимые позиции и покрытие расчётов.

Каждое название открывает определение с единицами, размером выборки и методом. Кнопки «Партии» ведут к исходным материалам выбранной строки.

### 10.2. Распределение потерь модельного очка

Изначально свёрнутый блок **Распределение потерь модельного очка** содержит таблицу **Гистограмма Lq**. Столбцы: **Потеря, п.п.**, **Решения**, шкала от 0 до числа пригодных решений, действие **Партии**.

Диапазон потери записывается как полуинтервал либо `≥{порог}`. Частота показана числом и горизонтальным синим прямоугольником. Если нет пригодных оценок, внутри блока — **Нет пригодных оценок**.

### 10.3. Качество по фазам

Таблица **Качество по фазам** использует общий временной формат: **Диапазон**, **Решения**, **Часы**, **Медиана, с**, **P25…P75, с**, **Всего, с**, **P90, с**, **Loss, п.п.**, **Потери ≥10 п.п.**. Строки соответствуют дебюту, миттельшпилю и эндшпилю. Название фазы переводит к связанным партиям.

### 10.4. Покрытие и исключения

Свёрнутый блок **Покрытие и исключения** содержит таблицу **Покрытие анализа**: **Причина**, **Партии**, **Решения**, действие **Партии**. Причина представлена текстовым статусом, например отсутствием анализа, WDL, часов или пригодной оценки.

При наличии сравнительных результатов также доступно общее раскрытие **Сопоставимые позиции и периоды**.

### 10.5. Измерения и позиции

Свёрнутый блок **Измерения и позиции ({количество})** содержит список показателя; в пунктах отображаются ID метрик группы Q. Выбранный ID определяет список случаев.

Таблица **Измерения решений**: **ID**, **Партия / ply**, **Событие**, **Значение**, **Фаза**, действия **Позиция** и **Данные**. «Позиция» открывает просмотр партии в нужном месте. «Данные» раскрывает текст подробностей измерения в предварительно форматированном блоке. Для следующих записей — **Ещё случаи**. При пустом списке — **Нет пригодных случаев**.

### 10.6. События

Под заголовком **События** располагается общая таблица **События партий** с подписью общего числа событий. Столбцы:

**Партия**, **Ply**, **Ход**, **Событие**, **Loss q, п.п.**, **Часы, с**, **Spent, с**, **Лучший**.

Идентификатор партии — кнопка перехода к позиции до решения. В событиях встречаются решения, существенные потери, возможности и упущенные возможности, потери преимущества, защитные эпизоды и утрата матового продолжения. Следующие события загружаются через **Ещё случаи**.

### 10.7. Загрузка и валидация

Свёрнутый блок **Загрузка и валидация** содержит таблицу **Покрытие загрузки**. Строки: **Принятые партии вне фильтра**, **Ожидают сверки**, **Диапазоны загрузки**, **Карантин**, затем причины отклонения с их количеством. Причины поступают из состояния загрузки и могут отображаться техническими названиями.

## 11. Статистика: Время

### 11.1. Временные показатели

Первой находится общая таблица метрик группы T. Среди её строк:

- **Время хода · медиана**, среднее, P25, P75, IQR, P90, максимум;
- **Известный расход часов**;
- **Остаток часов · медиана**;
- **Относительный остаток · медиана**;
- доля решений при остатке менее 10, 30, 60 секунд;
- доля решений при остатке менее 5% и 10% начального времени;
- доля партий с такими остатками и число соответствующих эпизодов;
- доля известного времени по дебюту, миттельшпилю и эндшпилю;
- **Покрытие качества по остаткам** и **Покрытие качества по расходу**;
- потери не менее 10 п.п. после длинного расхода и после короткого расхода при запасе;
- показатели для прочих решений в тех же условиях.

Единицы представлены секундами, процентами, числом решений или эпизодов в зависимости от строки. Отсутствующий расход либо остаток не заменяется нулём.

### 11.2. Таблицы времени

Последовательно показаны:

1. Заголовок **Остаток часов до решения** и таблица **Качество по остатку времени**.
2. Заголовок **Расход часов на решение** и таблица **Качество по расходу времени**.
3. Таблица **Время по фазам**.

У всех таблиц одинаковые столбцы: **Диапазон**, **Решения**, **Часы**, **Медиана, с**, **P25…P75, с**, **Всего, с**, **P90, с**, **Loss, п.п.**, **Потери ≥10 п.п.**.

Расход на решение разбит на интервалы **<1 с**, **1–3 с**, **3–10 с**, **10–30 с**, **≥30 с**. Остаток и фазы представлены своими группами. Название диапазона открывает связанные партии.

### 11.3. Временные условия и эпизоды

Блок **Временные условия и эпизоды** исходно раскрыт. Вверху — список **Временной показатель** с пунктом **Все** и имеющимися ID показателей.

Таблица **Временные условия**:

**Условие**, **Страта**, **Значение**, **N / доступно**, **Интервал**, **Loss, п.п.**, **Потери ≥10 п.п.**, **Состояние**, раскрытие **Случаи**.

Здесь представлены условия по абсолютному и относительному остатку, расходу, фазе и сопоставимым ситуациям, эпизоды нехватки времени, повторные позиции и окна решений. В названии условия могут присутствовать номер ply, порог, категория или другой контекст.

Для описательного межквартильного интервала к числам добавляется **IQR**, а при наведении показано **P25…P75**. Другие интервалы имеют подсказку **95% bootstrap целых партий**. При большом количестве строк есть **Показать ещё 100 строк**.

### 11.4. Остальные блоки

При наличии данных доступно раскрытие **Сопоставимые позиции и периоды**, ограниченное временными показателями. Ниже находится таблица событий партий, для которых известен расход или остаток часов. Формат таблицы событий совпадает с вкладкой «Качество игры».

## 12. Статистика: Реализация и эндшпиль

### 12.1. Реализация и защита

Первая таблица общего формата содержит показатели групп E и S. Состав конкретных строк зависит от обнаруженных типов позиций, эпизодов и наличия анализа.

Группа возможностей и реализации включает:

- возможности после ошибок соперника: число, частота на 100 ходов соперника, полученное улучшение — среднее, медиана, P90;
- **Использовано возможностей**, **Возможности без пригодного ответа**;
- сохранённую долю улучшения: среднее и медиану;
- использование восстановительных возможностей и восстановительные ответы к q≥0,50;
- утрату матового пути на 100 возможностей и число случаев, когда матовый путь не найден при перепроверке;
- партии с устойчивым преимуществом, реализацию преимущества, очки после преимущества, эпизоды преимущества и фазу первого входа;
- сохранение преимущества до завершения, длину эпизода, потери и ошибки при реализации;
- партии с трудным состоянием, спасённые трудные партии, очки после трудного состояния, защитные эпизоды;
- защитные потери и ошибки, возврат к q≥0,50 и первое наблюдаемое восстановление, с разделением по тому, после чьего хода оно наблюдалось.

Фазовые и эндшпильные строки включают:

- достижение и длину фаз, показатели качества по фазам;
- сегменты материальных типов окончаний, результаты, средние/медианные/P90 потери и частоты существенных потерь;
- время решения, сумму, долю и покрытие расхода времени по типам;
- ожидаемое очко при входе и часы первого решения;
- реализацию, защитные потери, ошибки и восстановление внутри материального типа и его контекстов;
- показатели при материальном перевесе и разных ожидаемых исходах входной позиции;
- показатели движкового и табличного эндшпильного анализа, включая WDL/DTZ при наличии данных;
- количества материальных составов, пешечных признаков, открытых/полуоткрытых файлов и точных пешечных форм;
- партии с позицией без ферзей и партии с обеими подтверждёнными рокировками.

Контекстные строки могут содержать в названии тип материала, пешечную форму, остаток времени или состояние входа. Прочерки и статусы показываются в тех же столбцах, что у других метрик.

### 12.2. Эпизоды преимущества и защиты

Свёрнутый блок **Эпизоды преимущества и защиты ({количество})** содержит таблицу:

**Тип**, **Партия**, **Вход / подтверждение**, **Выход / завершение**, **Последняя позиция, ply**, **Своих решений**, **Σ loss, п.п.**, **Состояние**, действия.

Тип — **Преимущество** или **Защита**. Границы представлены номерами полуходов. Последняя позиция — кнопка перехода. В конце строки — **Вход** и **Первая потеря**; вторая недоступна, если такого события нет. Дополнительные эпизоды загружаются через **Ещё случаи**.

### 12.3. Материал, пешечные структуры и рокировки

Свёрнутый блок **Материал, пешечные структуры и рокировки ({количество})**. Таблица **Позиционные признаки**: **ID**, **Признак**, **Партии**, **Посещения**, **Знаменатель**, **Доля, %**, действия **Случаи** и **Партии**.

Строки описывают наблюдавшийся материал, изолированные/сдвоенные/геометрически проходные пешки, открытые и полуоткрытые файлы, точные пешечные формы и переходы, позиции без ферзей и взятия ферзя, стороны и сочетания рокировок. Разные признаки могут относиться к одной партии и разным её посещениям.

Под блоком выводится **Syzygy: {состояние}**. При большом количестве данных есть **Показать ещё 100 строк**.

### 12.4. Детализация и окончания

При наличии сравнения доступен блок **Сопоставимые позиции и периоды** для соответствующих показателей реализации и защиты.

Далее расположен блок **Измерения и позиции** со списком ID метрик групп E и S. Он использует таблицу ID, партии/ply, события, значения, фазы и действий **Позиция**/**Данные**.

Ниже — заголовок **Типы окончаний** и таблица: **Группа**, **N**, **W / D / L**, **Очки, %**, **Loss, п.п.**, **Решений с анализом**. Типы представлены названиями **Пешечные**, **Ладейные**, **Ферзевые**, **Лёгкие фигуры**, **Смешанные** и другими группами из данных. Название группы открывает партии.

Завершает вкладку таблица событий: решения эндшпиля и события других типов, соответствующие фильтру этого представления.

## 13. Статистика: Партии и очередь анализа

### 13.1. Действия с анализом

Над списком партий расположены:

- **Анализировать выборку** — передаёт в очередь партии текущего отчёта, включая строки сверх первой видимой порции; недоступна при пустой выборке.
- **Пауза анализа** либо **Продолжить анализ**, в зависимости от сохранённого состояния очереди.

Настройка исполняемого файла движка находится в общих настройках, а не внутри этой вкладки.

### 13.2. Таблица собственных партий

Столбцы:

1. **Дата** — кнопка открытия партии.
2. **Соперник**.
3. **Рейтинг** соперника.
4. **Цвет** пользователя: Белые/Чёрные.
5. **Контроль, с+с**.
6. **Результат**.
7. **Дебют**.
8. **Accuracy**.
9. **Loss**.
10. **Решений с анализом** — использовано/всего или статус.
11. **Наблюдаемый интервал, с**.

Исходно отображаются первые 100 строк. Кнопка **Ещё 100 партий** расширяет список. Подсказка интервала различает **Подтверждённое завершение − начало** и **Последний ход − начало; не длительность партии**. Во втором случае рядом с числом стоит **· до хода**.

### 13.3. Очередь анализа

Свёрнутый блок **Очередь анализа ({количество})**. Если движок не настроен, внутри показано **Stockfish не настроен**.

Таблица: **Партия**, **Состояние**, **Позиции**, действие **Отменить**. Партия представлена ID-кнопкой. Прогресс — `{обработано}/{всего}`. Состояния включают очередь, анализ, готовность, паузу, отмену, повтор и ошибку; при наличии ошибки она дописывается к состоянию. Отмена доступна для задач в очереди или выполняющихся задач.

### 13.4. Отклонённые загрузки

При наличии записей появляется свёрнутый блок **Отклонённые загрузки ({количество})**. Таблица: **ID**, **Получено**, **Причина**, **Исходные данные**, действие **Загрузить повторно**.

В исходных данных есть отдельное раскрытие **JSON** с полным сохранённым ответом по отклонённой партии. Повторная загрузка недоступна, если наблюдение аккаунта отключено. Причина выводится текстом из состояния проверки данных.

## 14. Просмотр конкретной партии

### 14.1. Открытие и расположение

Просмотрщик открывается из списка партий, таблиц метрик и случаев, событий, дебютной аналитики и графа. Он занимает место содержимого текущей вкладки Statistics. Общие вкладки и фильтры остаются выше.

Верхняя строка: **{Белые} — {Чёрные}**, результат, **Закрыть партию**. Закрытие возвращает к содержимому выбранной вкладки. Переключение внутренней вкладки также закрывает просмотрщик.

Основная область — две колонки: доска слева и информация справа. Начальная ориентация доски соответствует цвету пользователя. Из ссылки на случай может сразу открываться нужный полуход, включая позицию до решения.

### 14.2. Доска и ходы

Доска работает в режиме просмотра: сделать новый ход фигурами нельзя. Под ней расположены **В начало партии** (`⏮`), **Предыдущий ход** (`◀`), **Следующий ход** (`▶`), **В конец партии** (`⏭`), **Перевернуть**. Переход назад/вперёд недоступен на соответствующей границе.

В правой колонке сначала показаны дата начала, категория контроля и способ завершения, затем название дебюта. Ниже — прокручиваемая запись партии. Ходы являются кнопками, текущий выделен, у ходов белых указан номер.

Под записью — пары значений: **Ход** (номер полухода), **Фаза**, **Часы, с**, **Затрачено, с**, **Материал** (числовой баланс).

### 14.3. Выбор анализа

Если есть движковые результаты, появляется список **Анализ**. В пункте — версия движка, режим **Быстрый/Стандартный/Углублённый** и первые восемь символов ID профиля. Когда ссылка запрашивает отсутствующий профиль, отображается **Нет анализа выбранного профиля**.

При доступной траектории показывается график **Ожидаемое очко модели по ходам**: горизонтальная ось ply, вертикальная — q в процентах с отметками 0, 50, 100. Активная точка увеличена и выделена зелёным. Клик, Enter или пробел на точке переводят доску к соответствующему полуходу. Пропущенные оценки разрывают линию. Без пригодных точек выводится **Нет траектории оценки**.

### 14.4. Оценка текущей позиции

Ниже располагаются поля:

- **q модели за белых/чёрных, %** — перспектива соответствует пользователю;
- **Accuracy следующего решения, %**;
- **Класс Lichess Advice**;
- **Оценка за белых** — в пешках, матовый формат `#…` или **нет оценок**;
- **Глубина**;
- **W / D / L, ‰**;
- **Следующее решение**;
- **Потеря после решения, п.п.**;
- **Лучший ход**.

При наличии показан текст **Варианта движка** в UCI и комментарий из записи позиции.

### 14.5. Исходные данные

В конце правой колонки — раскрытия **PGN** и **FEN**.

- **PGN** содержит поле только для чтения с исходной записью и кнопку **Копировать PGN**.
- **FEN** содержит поле только для чтения с выбранной позицией.

Ошибка загрузки позиции или копирования появляется текстом в той же колонке. Эти поля не редактируют исходную сыгранную партию.

## 15. Редактор репертуара

### 15.1. Входы и компоновка

Редактор открывается на вкладке **Граф партий**:

- кнопкой **Создать репертуар**;
- кнопкой **Редактировать репертуар** для документа из списка;
- нажатием **Подготовлено** или **Совпадение** у конкретного продолжения.

В последнем случае выбираются связанные глава и узел. При создании из графа начальная FEN заполняется выбранной позицией.

Редактор представляет собой диалог с затемнённым фоном, заголовком **Репертуар**, шириной до 1320 px или 96% ширины окна. Максимальная высота — 96% окна; содержимое прокручивается внутри. Во время его открытия рабочая область графа заменяется этим редактором, а основная оболочка Statistics остаётся под фоном диалога.

Порядок областей:

1. Заголовок, состояние сохранения, **Сохранить**, крестик.
2. Сообщение об ошибке, когда оно есть.
3. Название, сторона и действия PGN; при создании — начальная FEN и **Создать**.
4. Управление главами для существующего документа.
5. При включении — форма новой главы.
6. Доска слева; дерево, действия с вариантами и аннотации справа.
7. При открытии — секция импорта или экспорта PGN в нижней части диалога.

Доска в редакторе имеет ширину от 330 px, связанную с высотой окна, до 620 px; правая колонка занимает оставшееся пространство.

### 15.2. Заголовок и сохранение

Рядом с заголовком выводится одно из состояний:

- **Сохранение…** во время загрузки/операции;
- **Есть изменения** при изменённых полях;
- **Сохранено · v{ревизия}** для сохранённого документа.

Кнопка **Сохранить** показана для существующего документа и доступна при изменениях, если операция не выполняется. Крестик имеет доступное название **Закрыть редактор репертуара** и недоступен во время операции.

Закрытие существующего документа сначала сохраняет изменённые поля. Если сохранение не удалось, редактор остаётся открытым с ошибкой. Закрытие формы до создания документа закрывает её без создания репертуара. Клик по затемнённому фону не является действием закрытия редактора; общего обработчика Escape для закрытия этого диалога нет.

### 15.3. Создание репертуара

В начальной форме доступны:

| Элемент       | Исходное состояние и действие                                                              |
| ------------- | ------------------------------------------------------------------------------------------ |
| Название      | Текст «Новый репертуар»; редактируется                                                     |
| Сторона       | Белые, Чёрные, Обе стороны; исходно Белые                                                  |
| Начальная FEN | Поле с заполнителем «Стандартная позиция»; при входе из графа содержит его позицию         |
| Создать       | Создаёт документ и открывает его первую главу; недоступна при пустом названии или операции |
| Импорт PGN    | Открывает секцию импорта, позволяющую создать документ из текста или файла                 |

Пустая начальная FEN означает стандартную позицию. До создания документа области редактирования дерева и глав не показываются.

### 15.4. Метаданные существующего документа

В той же верхней строке остаются редактируемые **Название**, **Сторона**, **Импорт PGN** и **Экспорт PGN**. Поля начальной FEN уже созданного документа здесь нет; исходные позиции задаются по главам при их создании или импорте.

Экспорт предварительно сохраняет изменённые поля. При стороне «Белые»/«Чёрные» соответствующим образом ориентируется доска; её можно перевернуть отдельной кнопкой.

### 15.5. Главы

Следующая строка содержит:

- список **Глава** с названиями глав;
- редактируемое поле **Название главы**;
- **Добавить главу**;
- **Удалить главу**.

Смена главы сохраняет изменённые поля текущего документа и открывает исходный узел выбранной главы. «Удалить главу» недоступна, если глава одна.

«Добавить главу» показывает или скрывает встроенную форму:

| Поле/кнопка   | Поведение                                                          |
| ------------- | ------------------------------------------------------------------ |
| Название      | Название новой главы; пустое значение заменяется «Глава {номер}»   |
| FEN           | Необязательная исходная позиция, заполнитель «Стандартная позиция» |
| Создать главу | Создаёт главу и выбирает её исходный узел                          |
| Отмена        | Скрывает форму                                                     |

### 15.6. Доска и навигация

Доска разрешает легальные ходы из выбранной позиции. Пока загружается проверенный список допустимых ходов или выполняется сохранение, перемещение фигур недоступно.

Если сделанный ход уже есть среди продолжений, редактор переходит к этому узлу. Если такого продолжения нет, он добавляется в дерево и сохраняется. Сделанный ход в другой ветви не заменяет остальные варианты документа.

Под доской:

| Кнопка | Действие                                                        |
| ------ | --------------------------------------------------------------- |
| `│‹`   | Начало главы                                                    |
| `‹`    | Родительская позиция                                            |
| `›`    | Первый, то есть главный, вариант-продолжение                    |
| `↻`    | Перевернуть доску                                               |
| В граф | Сохранить изменения и открыть текущую позицию редактора в графе |

Кнопки начала и предыдущего хода недоступны в корне, следующего хода — без продолжений. Под кнопками находится моноширинное поле **FEN выбранной позиции репертуара**, только для чтения. При фокусе его содержимое выделяется целиком.

### 15.7. Дерево вариантов

Справа — прокручиваемое дерево **Варианты репертуара**. Первая строка — **Начало**, затем ходы с номерами и SAN. Варианты показаны отступами и знаком `↳`; боковые ветви имеют вертикальную границу. Глубина визуального отступа ограничена восемью уровнями, более глубокие узлы остаются в дереве.

Выбранный узел имеет акцентную заливку и белый текст. Узлы на текущем пути дополнительно выделены фоном. При выборе другого узла список прокручивается к нему.

Справа от записи хода могут отображаться:

- NAG в виде `$1 $14`;
- `{…}` при наличии комментария;
- `◇` при наличии графических аннотаций.

В первой порции выводится до 300 ходов. Кнопка **Ещё {оставшееся количество} ходов** увеличивает видимую порцию на 300.

Под деревом:

- **Главный вариант** — делает выбранное продолжение главным;
- **Удалить ветвь** — открывает подтверждение удаления узла и продолжений.

Оба действия недоступны для исходного узла главы и во время операции.

### 15.8. Подтверждение удаления

Под действиями дерева появляется встроенная строка подтверждения, а не отдельное системное окно:

- для ветви — **Удалить ветвь и продолжения** и **Отмена**;
- для главы — **Удалить главу с вариантами** и **Отмена**.

Подтверждение ветви удаляет выбранное поддерево и переводит выбор к его родителю. Подтверждение главы удаляет её и выбирает первую оставшуюся главу.

### 15.9. Комментарии, NAG и рисунки

Ниже действий с вариантами расположены:

| Элемент             | Содержание                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| Комментарий         | Многострочное редактируемое поле текста выбранной позиции                                          |
| NAG                 | Текстовое поле числовых аннотаций выбранного хода                                                  |
| Сохранить аннотации | Сохраняет изменённые аннотации и остальные изменённые поля; недоступна без изменений аннотаций     |
| Очистить стрелки    | Убирает рисунки выбранной позиции и отмечает аннотации изменёнными; недоступна, когда рисунков нет |

В поле NAG вводятся номера с `$` или без него, разделённые пробелами или запятыми. Допустимы числа 0–255. При ошибке отображается **NAG должен содержать номера: $1 $14** либо **NAG: допустимы номера от 0 до 255**.

Стрелки и круги редактируются непосредственно на доске. Сохраняются зелёный, красный, синий и жёлтый цвета. Пустые строки между абзацами комментария разделяют сохраняемые комментарии. При переходе к другому узлу или главе, операции с деревом, экспорте и закрытии редактор предварительно сохраняет изменённые поля.

### 15.10. Импорт PGN

Кнопка **Импорт PGN** открывает нижнюю секцию с заголовком **Импорт PGN**, крестиком и редактируемым многострочным полем **PGN для импорта**. Секция находится внутри того же диалога.

Ниже расположены:

- **Открыть файл** — стандартное поле выбора `.pgn` или текстового PGN-файла; выбранный файл загружается в текстовое поле;
- **Импортировать репертуар** для ещё не созданного документа либо **Добавить главы из PGN** для существующего.

Кнопка импорта недоступна при пустом тексте или выполняющейся операции. Для существующего документа импорт добавляет главы, сохраняя уже имеющиеся. После импорта выбирается первая добавленная глава, секция PGN закрывается. Поддерживаемые PGN-варианты становятся ветвями дерева; комментарии, NAG и аннотации отображаются в соответствующих областях.

Крестик **Закрыть PGN** скрывает секцию. Ошибка импорта отображается в общей области ошибки редактора.

### 15.11. Экспорт PGN

Секция **Экспорт PGN** содержит поле **Экспортированный PGN** только для чтения, крестик, **Копировать PGN** и **Скачать PGN**.

Копирование помещает текст в буфер обмена. Скачивание создаёт PGN-файл с названием репертуара; недопустимые символы имени заменяются подчёркиваниями. Экспорт включает главы и дерево вариантов с поддерживаемыми аннотациями. Повторный импорт выполняется тем же импортным интерфейсом.

### 15.12. Ошибки и занятость

Во время операции недоступны действия, способные одновременно менять документ; состояние заголовка — **Сохранение…**. Ошибка появляется непосредственно под заголовком.

Для загруженного документа рядом есть **Перезагрузить документ**, получающая сохранённую версию заново. Для формы до создания — **Закрыть**, убирающая сообщение. Ошибка не заменяет весь редактор отдельным экраном.

## 16. Знания, Мои партии и Тренировка

### 16.1. Знания

Пункт **Знания** открывает страницу с заголовком **Знания** под общей верхней навигацией. Других списков, полей или действий на этой странице в текущем интерфейсе нет. Редактор репертуара вызывается из графа, а не из этой страницы.

### 16.2. Мои партии

Пункт **Мои партии** выбирает внутри Statistics вкладку **Партии**. При этом заголовок содержимого остаётся **Статистика**, а семь внутренних вкладок, фильтры, состояния синхронизации, список партий и очередь анализа доступны в том же виде. Основное меню показывает активным пункт «Мои партии».

После входа через «Мои партии» пользователь может переключить любую внутреннюю вкладку Statistics. Открытая партия использует тот же просмотрщик, что при входе через «Статистика».

### 16.3. Тренировка

Пункт **Тренировка** открывает страницу с заголовком **Тренировка** под общей навигацией. Шахматного задания, формы запуска и списка упражнений на этой странице в текущей версии нет.

## 17. Общие списки детализации

### 17.1. Партии показателя или группы

Кнопка **Партии** в аналитике устанавливает выборку по связанным ID и переключает внутреннюю вкладку на «Партии». Над списком появляется **Выбрано партий: {число}** и **Снять выборку**. Остальные применённые фильтры продолжают участвовать в текущем состоянии.

### 17.2. Случаи

Раскрытия **Случаи**, **Решения ветви**, **Решения партии**, **Ответы**, **Окна решений**, **Посещения в предыдущем периоде** используют общий формат. В заголовке — название и общее число случаев. Таблица: **Партия**, **Ply**, кнопка **Открыть**.

В зависимости от вида случая открывается позиция на указанном полуходе либо перед соответствующим решением. Ссылка также может выбирать конкретный результат движкового анализа.

Если показана только часть данных, внизу есть **Ещё случаи**. Во время запроса текст кнопки — **Загрузка**, кнопка недоступна. Ошибка дозагрузки выводится рядом с этим списком. Общее число случаев может быть больше уже загруженного количества строк.

### 17.3. Сопоставимые позиции и периоды

Общее раскрытие **Сопоставимые позиции и периоды** встречается на «Обзоре», «Качестве игры», «Времени», «Реализации и эндшпиле», когда существуют данные прогресса. Таблица содержит ID и подпись условия, значения A и B, разницу, размеры обеих выборок, интервал, статус и переходы к случаям/партиям.

На вкладке «Время» показываются временные строки; на «Реализации и эндшпиле» — строки соответствующей условной аналитики. Порция отображения может расширяться кнопкой **Показать ещё 100 строк**.

## 20. Обновление данных и сохранение состояния

### 20.1. Автоматическое обновление

- Часы на главной обновляются раз в секунду.
- Состояние аккаунта проверяется примерно раз в минуту, а также при возвращении фокуса в окно и восстановлении соединения.
- Синхронизация партий выполняется при запуске и в процессе работы приложения; есть ручная кнопка в Statistics.
- Открытая Statistics обновляет состояние обработки примерно каждые 10 секунд, отчёт — по событию изменения данных и резервной проверкой примерно раз в минуту.
- После поступления новых принятых партий обновляются соответствующие статистические представления и граф.
- Изменение сохранённого репертуара обновляет доступные документы и его наложение.

Для пользователя ход синхронизации виден в строке Statistics, ход движкового анализа — в покрытии и очереди. Текущие онлайн-партии не являются экраном анализа в этой реализации: личная статистика пополняется завершёнными партиями.

### 20.3. Временные границы и фактические данные

Строка **Наблюдение с…** обозначает начало отслеживания аккаунта. Подключение не сопровождается отдельным обязательным мастером исторического импорта. До появления принятых завершённых партий статистика может иметь пустую выборку.

Модельные или импортированные в «Базы» партии не становятся личной статистикой только из-за нахождения в локальном хранилище. Репертуарные варианты отображаются отдельным слоем и не увеличивают фактические победы, посещения сыгранных ходов и количество собственных партий.

### 23.2. Данные и способ получения

Съёмка проводилась на отдельных тестовых профилях. Основной профиль содержит четыре легальные тестовые партии с сохранёнными результатами локального Stockfish; дополнительный — 1000 партий для графа. Репертуары и длинная линия подготовлены для съёмки. На изображениях используются тестовые имена; пользовательские партии, токены и подключение установленного приложения в набор не включены.

Для большинства снимков неизменённый production frontend работает через IPC-мост с запущенным Rust/SQLite backend. Для переходных состояний и ошибок задаётся ответ на границе IPC: интерфейс рендерится теми же компонентами. Такие записи в каталоге отмечены **IPC-состояние**. К ним также относятся показ строки прогресса и табличного наблюдения Syzygy; их значения служат для отображения полей и не являются результатом оценки игрока или фактического поиска таблиц.

Отдельные записи **Native** сняты непосредственно в клиентской области Tauri/WebView2. Подробности получения и дополнительные примечания к конкретным состояниям находятся в манифесте. Системные окна выбора файла и внешний сайт авторизации не включены в развёртку клиентской области приложения.

### 23.3. Чтение изображений

У длинных страниц и раскрытий части пронумерованы и идут сверху вниз с перекрытием. Диалог редактора с внутренней прокруткой снят в нескольких положениях; это отдельные части одной конфигурации. Оригиналы PNG сохраняют исходный размер без добавленных поверх приложения подписей или ретуши.

Для передачи материалов следует сохранять рядом этот файл и папку `screens/`: ссылки в отчёте, каталоге и галерее относительные. Значения числовых полей, даты и FEN представлены тестовыми примерами; развёртка организована по видам экранов и состояний, а не по каждой возможной комбинации значений.
