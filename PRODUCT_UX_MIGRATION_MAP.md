# ChessPush — карта переноса интерфейса

Сверка с исходным кодом: 18 октября 2026 года. Исходное представление описано в `CHESSPUSH_CURRENT_UI.md` и визуальном каталоге `screens/` от 17 октября. Основание переработки — `CHESSPUSH_PRODUCT_UX_REDESIGN_TASK.md`.

Это справочник доступности действий и данных, а не протокол GUI-приёмки. Выполненные проверки и ограничения фиксируются отдельно в `PRODUCT_UX_ACCEPTANCE.md` и итоговом отчёте. Названия маршрутов ниже означают разделы приложения: в текущем React UI переходы управляются состоянием, а не отдельным URL для каждого экрана.

Уровни представления:

- **Работа:** видимые действия с партиями, продолжениями и документами.
- **Подробности:** тематические представления и раскрываемые исходные случаи.
- **Технические сведения:** методы, профили, идентификаторы, исходные ответы и диагностика обработки.

## Основная навигация

| Прежний вход | Текущий вход | Содержимое и сохранённые действия |
|---|---|---|
| Логотип / кнопка с домом | Главная; логотип ChessPush | Продолжить сохранённую работу, последние собственные партии, существующие репертуары; часы и рейтинг вторичны |
| Статистика | Моя игра | Обзор · Карта игры · Партии; тематические вычисления открываются командой «Подробная статистика» |
| Мои партии | Моя игра → Партии | Тот же список фактических личных партий и просмотрщик; внутренний идентификатор `games` сохранён |
| Граф партий внутри Statistics | Моя игра → Карта игры | Основной локальный экран продолжений; общая карта доступна дополнительным действием |
| Репертуар только из графа | Репертуар | Самостоятельный список и редактор тех же KnowledgeDocument; вход к конкретному узлу из карты |
| Базы | Библиотека | Поиск позиции/дебюта, источник, отбор, потоковый парсер, сохранённые файлы, просмотр извлечённых партий |
| Знания — пустая страница | Нет активного пункта главного меню | Полный Knowledge UI не имитируется; действующий документный редактор репертуара использует общее ядро |
| Тренировка — пустая страница | Нет активного пункта главного меню | Полный Training/SRS не реализуется в этом этапе |
| Шестерёнка | Настройки | Аккаунт · Внешний вид · Движок · Диагностика |

`App.tsx` сохраняет совместимость внутреннего входа `games`, направляя его в Statistics с выбранным списком партий. Документы, game IDs, chapter/node IDs и таблицы первичных данных не переименовываются вслед за надписями меню.

## Главная и возвращение к работе

| Прежний элемент | Новый маршрут / действие | Граница поведения |
|---|---|---|
| Часы в центре экрана | Главная → компактное время | Фактическое время; не отдельная задача подготовки |
| Rapid / Blitz и ник | Главная → строка рейтингов | Рейтинг аккаунта остаётся рейтингом Lichess; не объединяется с качеством решений |
| Полоса продвижения к 2000 | Не выводится как ведущее действие | Фиксированная цель интерфейса не относится к контракту метрик Statistics |
| Единственный вход через авторизацию | Подключить Lichess, если нет практики; иначе открыть карту | Локальные документы репертуара доступны независимо от авторизации |
| Отсутствие возвращения к материалу | Продолжить | Адрес последней работы: раздел, партия/ход либо документ/глава/узел; граф дополнительно использует сохранённый нативный контекст |
| Отсутствие списка новых материалов | Последние партии / Репертуар | Ограниченные проекции существующих данных, без вымышленных партий и отметок человеческого разбора |

Адрес рабочего места хранится как UI-настройка (`workspace.ts`), а не как копия PGN или альтернативное хранилище знаний. Сохранение графа и документа описано ниже.

| Время — все таблицы на одном уровне | Подробная статистика → Время | Основное представление времени/качества; подробные показатели, расход, фазы и контексты — в раскрытии |
| Реализация и эндшпиль | Подробная статистика → Реализация и окончания | Основной срез окончаний; эпизоды преимущества/защиты, структуры и исходные измерения — в раскрытии |
| Таблица всех показателей по нескольким вкладкам | Подробная статистика → Все показатели | Поиск по названию или прежнему ID; определения, N, интервалы и переход к исходным партиям сохранены |
| Нажатие названия метрики | Определение показателя | Единицы, определение, знаменатель и метод; технический ID не служит названием раздела |
| Партии метрики / группы / интервала / события | Моя игра → Партии с ограниченной выборкой либо точный момент в viewer | Основание отбора остаётся в фильтре; можно вернуться ко всей практике |
| Строка синхронизации с диапазонами и T0 | Короткое обновление в Моя игра; Настройки → Диагностика | Ошибка синхронизации с повтором видна в обычном UI; T0, pending ranges и raw response находятся в диагностике |
| Длинные таблицы при отсутствии данных | Отдельное пустое состояние | Нет аккаунта, нет новых партий, пустой фильтр, нет анализа и ошибка запроса различаются |

## Каталог метрик: полное покрытие семейств

Определения 86 базовых ID остаются в `STATISTICS_METRICS.md`. Ниже указан путь ко всем семействам; это не новый набор расчётов. Дополнительные строки, полученные стратификацией по условиям, не становятся отдельными пунктами навигации.

| Базовые ID | Предмет | Основной доступ | Дополнительный доступ / ограничение |
|---|---|---|---|
| **G01–G16** | Результаты, активность, рейтинг | Подробная статистика → Результаты и динамика → Показатели и исходные случаи | Все показатели; выборка, интервалы и исходные партии из строки метрики |
| **O01–O15** | Дебюты, варианты, позиции, продолжения и репертуар | Подробная статистика → Дебюты → Показатели и исходные случаи | Числовой срез ведёт на общую карту; Все показатели |
| **Q01–Q11** | Качество решений и движковые события | Подробная статистика → Качество → Показатели и исходные случаи | Основные реальные случаи доступны и в обзоре; Все показатели |
| **E01–E11** | Упущенные возможности, реализация и защита | Подробная статистика → Реализация и окончания → Показатели и исходные случаи | Эпизоды, точные ходы и движковое evidence; Все показатели |
| **T01–T10** | Управление временем | Подробная статистика → Время → Показатели и исходные случаи | Расход/остаток/фазы, качество часов, события и исходные партии; Все показатели |
| **S01–S14** | Фазы, окончания и объективные структурные признаки | Подробная статистика → Реализация и окончания → Показатели и исходные случаи | S01 дополнительно в «Качество»; структурные признаки не получают стратегических причинных ярлыков; Все показатели |
| **P01–P09** | Динамика, сопоставимость, покрытие и исследовательские возможности | Подробная статистика → Качество → Показатели и исходные случаи | Наблюдаемые ряды и сравнения также в «Результаты и динамика», контекст прогресса — в предметных раскрытиях; Все показатели |

Ограничения доступности не скрываются переименованием:

- O14/O15: существование репертуарного редактора не означает готовность расчёта покрытия и освоения репертуара. В подробностях дебютов указано отсутствие именно расчёта; прежнее сообщение «модуля репертуара нет» заменено.
- P05–P09 и другие недоступные исследовательские показатели сохраняют свой статус. Переработка UI не добавляет автоматическое распознавание стратегических причин, AI-тренера или оценку эффективности тренировки.
- Отсутствующая оценка, непригодные часы и ещё не выполненный расчёт не превращаются в нулевое значение. Это относится и к каталогу, и к компактным представлениям.
- Шкалы Accuracy, ACPL и потерь модельного очка не объединяются. Порог собственной метрики Lq не называется автоматически стандартным Lichess Advice.

## Карта игры

| Прежний элемент / действие | Новое место | Сохранённый контракт |
|---|---|---|
| Cytoscape как первый экран большой сети | Карта игры → локальные продолжения | Вершина предметной модели остаётся позицией; видимый жетон показывает переход по конкретному ребру текущего пути |
| Прямоугольник SAN + N + visits + W/D/L | Жетон хода и сопровождающая строка | Ход — цель нажатия; число реальных партий и результат находятся рядом, технические значения отдельно |
| Начальная необходимость Fit/Pan | Локальный список продолжений с доской | Первые варианты доступны без камеры; стрелка наведения не меняет выбранную позицию |
| Глубина 1–5 и top-K в основной панели | Локальное «Ещё N продолжений»; компактные превью | Локальное раскрытие соседних ходов не меняет глобальную глубину и знаменатель |
| Все стрелки продолжений на доске | Одна стрелка hover/focus; цели выбранной фигуры | Ход с доски и жетона выполняет один и тот же переход; просмотр не создаёт сыгранную партию |
| ←/→ как неочевидная история посещений | Назад по ветви; кликабельный путь; клавиатура исследования | Возврат по выбранному префиксу, не по случайному родителю общей позиции |
| «Обзор» как возврат в начало | Начало в истории ветви | Отдельная команда «Общая карта» означает дополнительный обзор, а не возврат к корню |
| Граф всех транспозиций без обозначения знаменателя | Эта ветвь / Со всеми порядками ходов | Агрегирование позиции отличается от подтверждённого полного пути; другой порядок открывается через реальное посещение |
| Таблица всех продолжений постоянно под графом | Данные рядом с продолжением; подробности позиции по запросу | Посещения и уникальные партии не смешиваются; доли не считаются только по видимой части |
| Большая сеть и перетаскивание вершин | Общая карта → ограниченный фрагмент | Обзор использует тот же индекс; UI обозначает предел фрагмента, pan/zoom дополнительны, вершины не редактируют факты |
| FEN, profile, depth, техническая оценка позиции на основном экране | Технические данные позиции | Идентичность позиции и происхождение оценки сохраняются |
| Список подтверждающих партий постоянно под графом | Партии хода / Партии этой позиции | Открываемый список с подгрузкой; точный game/ply и возврат к вызвавшей ветви |
| Потери ветви без практического входа | На разбор в этой ветви | Только существующие пригодные события; основание и точный момент в просмотрщике |
| Отдельный включённый флажок пустого репертуарного слоя | Выбор документа / Без репертуара | Подготовленные ходы не увеличивают N, частоты и результаты реальных партий |
| Неподписанная подготовленная линия | Подготовлено / В репертуаре / Вне репертуара / Ответ без подготовки | Подготовленный ход без практики имеет «Пока не встречалось», а не 0% побед |
| Первая найденная ссылка на документ | Выбор соответствующего document/chapter/node | При нескольких соответствиях показывается выбор |
| Создание/редактирование из полотна в модальном диалоге | Самостоятельный Репертуар; переход к узлу и «К ветви» | Тот же документ и устойчивый узел; обратный переход сохраняет контекст карты |

Рабочий путь, репертуарный слой и обзор графа сохраняются через прежний нативный механизм `game_graph_state`. Render ID и координаты не становятся идентификаторами шахматных объектов.

## Партии и просмотрщик

| Прежний элемент / действие | Текущий путь | Подробности |
|---|---|---|
| Мои партии и внутренняя Партии | Моя игра → Партии; недавние партии с Главной; подтверждения карты/метрик | Личная партия открывается общим `BoardView` и запросом `statistics_game` |
| Широкая таблица всех полей | Компактные основные колонки | Дата, соперник, сторона, результат, дебют, готовность анализа; полная сохранённая партия доступна в viewer |
| Viewer под общей шапкой фильтров | Самостоятельное представление выбранной партии | Доска, нотация, выбранный момент, траектория при наличии, возврат |
| Переход из ошибки | Открыть момент | Позиция перед решением, сыгранный ход; проверенная альтернатива только по явному действию |
| Данные cp/mate/depth/clock/material/PV постоянно рядом | Подробности позиции и анализа | Выбранный профиль и версия evidence не подменяются другими запусками |
| Исходный PGN/FEN в основной рабочей области | Раскрытия PGN / FEN | Исходные данные остаются доступны |
| Длинная очередь движка под списком партий | Партии → Анализ партий | Анализ выборки, пауза/продолжение, прогресс, отмена, повтор ошибки и вход в настройки |
| Карантин ниже очереди | Настройки → Диагностика → Отклонённые загрузки | Raw input и повторная загрузка; повреждённая запись не становится сыгранной партией |

Справочные партии Библиотеки не присваиваются личной статистике. Их файловый список и просмотр используют библиотечные запросы и общий `ChessBoard`/`BoardSession`; список личной практики не смешивается с импортированной модельной базой.

## Репертуар и общий редактор

| Прежний элемент / действие | Текущее место | Сохранённые данные и безопасность |
|---|---|---|
| Единственный вход через граф | Репертуар → список | Название, сторона, последнее изменение; только документы kind=repertoire |
| Создание документа внутри большого диалога | Репертуар → Создать | Название и сторона; нестандартная начальная позиция в дополнительном раскрытии |
| Полный экран закрывается крестиком | К репертуарам; при входе из карты — К ветви | Переходы завершают сохранение; ошибка не закрывает редактор молча |
| Метаданные, FEN и PGN над доской | Заголовок; Документ; техническое раскрытие позиции | Title/side и импорт/экспорт доступны; FEN и ревизия не занимают постоянную рабочую область |
| Выбор и переименование главы | Выбор главы; Настройки главы | Те же главы и ID; добавить главу — отдельная короткая форма |
| Удаление главы/ветви | Настройки главы / Удалить ветвь → подтверждение | Удаление не выполняется по первому неявному действию |
| Длинный файловый список полуходов | Последовательная нотация и локальное раскрытие альтернатив | Представление строится над тем же VariationTree; длинный материал раскрывается порциями |
| Главный вариант | Действие выбранного хода | Нативная операция promote_variation сохраняет устойчивые узлы |
| Номера NAG в основном поле | Оценка хода → шахматные символы | Числовое редактирование в дополнительном раскрытии; неизвестные поддерживаемые NAG сохраняются |
| Комментарий и графические аннотации | Комментарий выбранной позиции; рисование на доске | Те же comments/nags/shapes; стрелки не заменяются текстовыми описаниями |
| PGN-секция под всей страницей | Документ → Импорт PGN / Экспорт PGN | Ограниченная задача с file/text import, copy/download и локальным отображением ошибки |
| Сохранено · vN | Сохранено / Сохраняется / Есть изменения / Не удалось сохранить | Ревизия скрыта в технических сведениях, но optimistic concurrency остаётся |
| Ошибка и перезагрузка документа с потерей текста | Повторить сохранение / Сверить с сохранённой версией | Текст остаётся видимым; сверка явно получает последнюю версию, не удаляя пользовательский ввод |
| Закрытие/перезапуск с несохранённым текстом | Восстановленный черновик редактора | UI-черновик не заменяет авторитетный нативный документ; ввод во время сохранения защищён поколением изменений |
| Черновик узла, удалённого в другой версии | Отдельный восстановленный текст | Не прикрепляется к случайному корню или другому узлу; доступно копирование |

Сохраняется общее ядро `KnowledgeDocument + Chapter + VariationTree`, команды `knowledge_*`, прежние документные ревизии, ссылки и нативное хранение. Самостоятельный маршрут не создаёт отдельный формат репертуара.

## Настройки, диагностика и техническое evidence

| Прежний элемент | Новое место | Что остаётся доступно |
|---|---|---|
| Токен первой формой | Настройки → Аккаунт → Войти через Lichess | Браузерный OAuth — основное действие, отмена ожидания и повторное подключение |
| Ручной токен | Аккаунт → Подключить вручную по токену | Маскированный ввод, очистка после отправки; секрет не попадает в UI-отчёт |
| Отключение | Настройки → Аккаунт | Прежний безопасный механизм; локальные партии и документы не очищаются |
| Переключение темы | Настройки → Внешний вид | Две темы; сохранение штатной настройкой |
| Все параметры Stockfish одной формой | Настройки → Движок | Путь, проверка готовности и режим анализа; низкоуровневые параметры в «Дополнительные настройки» |
| Threads, Hash, nodes, milliseconds, Syzygy | Движок → Дополнительные настройки | Профиль не меняется неявно при смене подписи |
| UCI identity / технические параметры | Технические подробности движка | Фактическая проверка выбранного исполняемого файла |
| T0, pending games/ranges, retry/error codes | Диагностика → Источник и наблюдение | Граница наблюдения и правила eligibility сохраняются |
| Profile hashes, evidence revision, job attempts | Диагностика → Анализ и версии | Источник и сопоставимость расчётов, техническая очередь |
| Raw quarantine | Диагностика → Отклонённые загрузки → Исходные данные | Причина отклонения и повторная загрузка |
| Raw evidence конкретного измерения | Тематическая статистика → Показатели и исходные случаи → Измерения и позиции → Данные | Технические сведения доступны в контексте объекта; не удалены при скрытии из повседневного экрана |
| Точное определение показателя | Нажатие названия показателя | Метод, единицы и пригодный знаменатель |
