# Текущий этап: Home / ZST

Состав оболочки заменён по последнему запросу: Home, ZST, компактное окно
настроек. Прошлые концептуальные страницы v2 остаются планом развития.

## Зависимости

```text
Main.qml / ParserPage.qml
  ├─ BoardController → BoardSession → python-chess
  │    └─ Qt WebChannel ↔ local board.js → @lichess-org/chessground 10.4.0
  ├─ ParserController → DatabaseExtractionWorker
  │    ├─ existing iter_matching_games_from_path → PGN / ZST stream
  │    ├─ existing PGN exporter
  │    └─ FileLibrary → existing SQLiteStorage / GameRecord
  ├─ ParserController → PgnImportWorker → managed PGN copy + same game store
  └─ SettingsController → existing SettingsStore
```

BoardSession не зависит от Qt. Легальность, полный FEN, история текущей линии,
превращение и аннотации принадлежат Python. Chessground отвечает за события
мыши, анимацию и рисование. Поле revision отклоняет ходы для устаревшей позиции.
В WebChannel зарегистрирован только маленький QML-адаптер состояния доски;
настройки, токен и файловые операции не доступны странице.

Парсер получает снимок фильтров и текущий префикс ходов при старте задачи.
Чтение, экспорт и сохранение партий выполняются в рабочем потоке. Старая
реализация фильтров и потокового ZST-чтения переиспользована; worker извлечён
из старого контроллера. Чтение обычного PGN теперь тоже идёт по партиям.

FileLibrary добавляет таблицы library_files и library_file_games, сохраняя
существующие таблицы и идентификаторы партий. Импортированный PGN имеет
управляемую копию; сырой ZST хранится как ссылка на исходный файл. Повторный
выбор одного пути не создаёт новую запись. Отсутствие файла не удаляет историю
или партии. Дедупликация партий использует существующую модель SQLiteStorage.

Из активного запуска удалены StatisticsController и PositionLabController;
их код и данные не удалены. Старый DatabaseLoaderController остался совместим
с прежними тестами, но в новом UI не используется. Миграция Qt framework,
отдельная БД знаний, движок и новая модель вариантов в этот этап не входят.

## Проверка

Unit-тесты проверяют легальные/нелегальные и устаревшие ходы, рокировку,
взятие на проходе, выбор фигуры, PGN из FEN, навигацию и аннотации; а также
повторный импорт, перезапуск хранилища, управляемую копию, ZST-извлечение,
сохранение частичного результата, отсутствующий файл и недопустимые фильтры.

tools/smoke_ui.py использует настоящие события Qt → Chromium → Chessground →
WebChannel с временным профилем. Пользовательские данные тест не открывает.
